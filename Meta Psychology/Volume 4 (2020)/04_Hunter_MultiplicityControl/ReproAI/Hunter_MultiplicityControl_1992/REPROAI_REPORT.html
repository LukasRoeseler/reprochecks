Findings (for the authors / editor)

P2 — medium

adv-002 — The shipped R script is a stripped demonstration file, not the full analysis. OSF GUID xrq3k is available and runs, but hardcodes nsim<-5 (line 13) and a single mean configuration (7-group non-null); the other 11 configurations are comment-blocked (lines 23–33). Running it as-is prints one nsim=5 row (no 3-decimal fidelity) rather than the manuscript's Tables 3–8. Reproduction requires the user to raise nsim to 5000 and loop the configurations (=108 conditions). Cause: archived development/demo version. Evidence: hunter_author_sim.R:13,23-33; live run status 0. Why it matters: present-and-correct-but-under-configured; the primary code does not directly regenerate the reported tables. Fix: ship with nsim<-5000, an explicit loop over all 12 configs, and a seed; archive the output tables.

P3 — low

adv-003 — Replication-study variances are written to swapped meta-variance columns. In the FE meta-analysis preparation, rep1 variance is stored at k+npair*2 and rep2 variance at k+npair (lines 117–125), opposite to meta_d. Effect is negligible for the headline (n=100 meta cells reproduced, live run .993 vs .994) but a latent defect behind the small-n meta deviations. Fix: swap the two column indices to k+npair / k+npair*2.

adv-004 — No random seed set or reported. Author code has no set.seed() and the paper reports none. Verified seed-stable: cross-seed FWER drift ≤ 0.005. Fix: add and report a seed for exact reproduction.

adv-005 — Author code is computationally impractical for full reproduction. In-loop metafor::rma makes a single condition at nsim=500 take ~355 s and nsim=2000 exceed 900 s; full 5000×108 would take days (independent base-R reimpl did 12×5000 in 205 s). Fix: replace in-loop meta with a precomputed closed-form inverse-variance weighted z-test.

adv-006 — No archived reproduction log/output for the "analysis reproduced by" badge. The claim is consistent with our independent reproduction, but OSF holds only the script/manuscript/cover letter — a reader cannot witness the editor's run. Fix: archive the reproduction log and tables.

What this audit does not guarantee

  • No human empirical data. This is a synthetic Monte-Carlo paper; there is no raw dataset to audit, and no claim herein covers empirical subject data.
  • Simulated values are seed-sensitive. Because the manuscript reports no seed, cell-perfect (bit-for-bit) reproduction of every 3-decimal table entry is not guaranteed; agreement is judged against Monte-Carlo sampling error at nsim=5000 (~0.006). A full re-run at the authors' exact (unreported) seed would be required for byte-level table equality.
  • The author code was not run end-to-end at nsim=5000×108 (computationally impractical, adv-005). Live execution was demonstrated at nsim=5 (as-shipped) and nsim=500 (one condition); full-table reproduction rests on the independent reimplementation plus the author-code logic match at scale.
  • Meta-analysis cells at small sample sizes (n=25) carry an implementation-difference caveat between the independent FE-meta (closed-form z) and the author's metafor::rma (+ variance-swap bug); direction and magnitude of the paper's meta conclusions are nonetheless reproduced.
  • The editorial "analysis reproduced by: Erin M. Buchanan" run was not witnessed; no log is archived (adv-006). Our independent reproduction is consistent with it but does not prove that specific run occurred.
