Reproduction detail

Example 1 (Fleishman / NORTA). The paper solves the Fleishman (1978) 3rd-order polynomial system for a target population skewness of 1 and excess kurtosis of 15, using nlminb from the start vector (0, 0, 1). Re-running the exact fleishman function reproduces the reported coefficients b = 1.534711, c = 0.170095, d = -0.306848 (and hence a = -c) to all reported decimals.

Example 2 (Gaussian copula). The paper simulates a bivariate standard normal (rho = 0.5), applies the probability integral transform, then Gamma (shape 1, rate 1) and Uniform(0,1) quantile functions. Re-running the code reproduces cor(Z) = 0.50021 and cor(Y) = 0.44047, giving a shrinkage of 0.0597, which matches the paper's "shrinkage of about 0.05-0.06 units" and its statement of a ~0.15-unit downward bias at the theoretically maximum correlation.

Agreement. Both reported numerical outputs reproduce to the paper's rounding. The article's central message - that the choice and implementation of a non-normal simulation algorithm (NORTA/Fleishman vs Gaussian copula) materially affects the resulting moments and correlations, and that these effects are often not acknowledged - is supported by the reproduced code examples.

Advisory items

  • ADV-001 (P3). The article is a methodological review with no empirical results; the reproduction verifies the illustrative code examples, not a substantive finding.
  • ADV-002 (P3). In the Fleishman example, the sample excess kurtosis of the generated data (n = 100,000) is ~10.8 rather than the target 15; this is expected for a heavy-tailed distribution where the 4th moment is dominated by rare extremes and is consistent with the paper's own discussion of the limits of the 3rd-order polynomial method.
