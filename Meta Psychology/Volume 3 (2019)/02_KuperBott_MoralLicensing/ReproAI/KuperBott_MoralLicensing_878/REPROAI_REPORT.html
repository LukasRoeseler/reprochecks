The conceptual headline of this paper is recoverable, but the packaged analysis cannot regenerate the manuscript's k=76 tables. A faithful independent re-derivation of the paper's own Table 1/2 rules from the raw archived data reproduces the sample construction exactly — k=76 with North America=40, Europe=30, South-East Asia=1 (all matching Table 3) — and reproduces the overall naïve effect size almost exactly (d=0.266, 95%CI [0.181;0.350] vs manuscript d=0.27 [0.19;0.35]). The uncorrected comparison moderator (β=−.42, Z=−3.72, p<.001) and the single South-East-Asian study (d=−.372, matches −.37) reproduce exactly or very well. However, (ADV-001, P1) the definitive k=76 analytic dataset and the Table 1/2 aggregation code were never archived — the shipped script analyses a different k=102 set whose output (d=.253, PET d=−.10, 3-PSM d=.105, X²(1)=11.67) does not match the manuscript's Table 3 (d=.27, PET d=−.05, 3-PSM d=.18, X²=3.42), so the "analysis reproduced & verified" badge was checked against a different analysis than the one reported; and (ADV-002, P1) the manuscript's own heterogeneity value I²=.26 is internally inconsistent with its own Q(75)=175.77, which implies I²≈57%. Secondary/exploratory values (Z=6.57 vs my 6.17, 3-PSM, appendix simulations) are not exactly reproducible (P2). No P0 blocker: the substantive conclusions (publication-bias-adjusted d≈0, culture moderation, comparison moderator) hold up directionally from the raw data.

Findings (for the authors)

P1 — high

ADV-001 — The primary k=76 analytic dataset and its Table 1/2 derivation code are not archived; the shipped script analyses a different k=102 set that does not reproduce Table 3. The archive ships only reviewer,analysis_JH.R (loads dat_new_s.txt, k=102) and the raw dat_{new,old}_{s,b}.txt files; there is no k=76 dataset and no code applying the Table 1 exclusions / Table 2 aggregations. Running the shipped script gives naive d=.253, I²=62%, Q(101)=257.6, PET d=−.10/slope 1.47, 3-PSM corrected d=.105 with X²(1)=11.67 (p=.0006) — none of which match the manuscript's k=76 Table 3 (d=.27, I²=.26, PET d=−.05, 3-PSM d=.18, X²=3.42). Consequently the p.14 statement "verified that the analysis reproduced the results presented in the article" (Open Data/Materials badge, verified by R. Carlsson) holds for the k=102 reviewer analysis, not for the k=76 analyses actually reported. Fix: ship the k=76 dataset and the exclusion/aggregation script (incl. the Simbrunner multi-outcome pooling method), state which analysis the badge covers.

ADV-002 — Reported heterogeneity I²=0.26 is internally inconsistent with the paper's own Q(75)=175.77 (which implies I²≈57%). Using the standard relation I²=(Q−df)/Q with the values the paper itself prints gives (175.77−75)/175.77=0.573. A reported I²=.26 cannot coexist with Q(75)=175.77 for the same model; the reconstruction likewise gives I²≈62–66%. Fix: recompute I² from the fitted k=76 model and correct the printed value (expected ≈0.57 from their own Q).

P2 — medium

ADV-003 — Precise secondary statistics are not exactly reproducible because the definitive k=76 dataset is missing. My faithful re-derivation gives d=.266 CI[.181;.350] Z=6.17 vs manuscript d=.27 CI[.19;.35] Z=6.57 (Z off by 0.40); EUR 3-PSM .212 vs .11; NOA PET slope 1.97 vs 2.12; Q 187.75 vs 175.77. Two aggregation variants for the 5 Simbrunner outcomes per sample (simple-mean vs inverse-variance pool) gave Z=6.17 and Z=5.92, neither hitting 6.57 — so the exact manuscript dataset is not reconstructable from the archive. Fix: covered by ADV-001.

ADV-004 — Appendix A1 simulation, Figure 3 selection-threshold exploration, and funnel-plot source data are not archived. No simulation code, no Fig 3 code/scans, and no k=76 funnel data are in the OSF archive; the exploratory/simulation claims (averaging bias > d=.10; selection threshold d≈0; Bonferroni n=981) are therefore not independently verifiable (C39–C41 ➖, C24/C32 partial). Fix: ship appendix simulation code + seeds and Fig 1/2/3 source data.

P3 — low

ADV-005 — Dataset-comparison claims (93% / k=85 / 6 ES / 6 N; "100%/100% identical") have no shipped derivation script. The original dat_old_s/b files are present but no study-to-study map/diff script is shipped (C1–C6 ➖). Fix: add the Table 1 comparison script.

ADV-006 — Background meta-analytic figures (d=.31, d=.32, fail-safe N=4531, n=801/1274/3134) are citations, not independently recomputable from this package. They come from Blanken (2015), Simbrunner & Schlegelmilch (2017), Ebersole (2016) etc.; no raw source for them is in the archive. Fix: none required for this manuscript.

What this package already does right

  • Data are genuinely open: raw per-study effect sizes and SEs for both the corrected (k=102/k=90) and uncorrected (k=106/k=91) Blanken and Simbrunner datasets, plus a codebook, are archived.
  • Table 1/2 rules are documented precisely and reproducibly: my independent re-derivation from the raw data under those rules reproduces the sample construction exactly (k=76; NOA=40/EUR=30/SEA=1), confirming the written methods are faithful to the resultant analytic set.
  • The headline magnitude and the direction of every moderation/pressure finding reproduce. Overall d≈0.27, the uncorrected comparison moderator (β=−.42), the single SEA study (d=−.372), and the NA/EUR subgroup PET values all come out in agreement.

What this audit does not guarantee

  • No live reproduction of the true k=76 analysis. Because the authors never shipped that dataset or its aggregation code, I could not run the genuine k=76 analysis end-to-end; I ran (a) the shipped k=102 script and (b) my own faithful re-derivation of the k=76 set. A definitive byte-level check of Table 3 is impossible until the authors upload the k=76 set.
  • 3-PSM-with-moderators values (C32) and the Appendix A1 / Figure 3 simulations are not checked (no code/data/seed archived).
  • The "93% / 95% / 6 discrepancies" comparison claims (Table 1 preamble) are not regenerated (no mapping script).
  • Background numbers quoted from prior papers are not recomputed from the archive (they are citations).
  • Funnel plots (Fig 1, 2) are only reported as visual asymmetry; no k=76 funnel data were shipped, so asymmetry is not regenerable here.
