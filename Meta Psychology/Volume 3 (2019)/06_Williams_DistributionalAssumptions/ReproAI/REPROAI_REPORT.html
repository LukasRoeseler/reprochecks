Verdict summary

This is a clean reproduction of the paper's worked example. The article is primarily methodological guidance, but it contains a concrete, fully-specified worked example (the Schroeder & Epley 2015 Experiment 4 intellect ratings, n = 39: 18 written, 21 spoken) that is used to illustrate four preregistration strategies. Re-running the analysis from the Table 1 data in R 4.6.1 (WRS2 for the robust methods) reproduces every load-bearing test statistic to the paper's reported rounding, and the paper's central illustrative conclusion - that all four strategies yield a significant difference favouring the spoken/audio group - holds exactly.

Reproduction detail

Data. The Table 1 values were transcribed from the paper and verified by cross-checking the two-sample Student's t statistic (which is extremely sensitive to the data): written (n = 18) 1.67, 2.00, 2.67, 2.67, 3.00, 3.33, 4.33, 4.33, 4.67, 4.67, 4.67, 4.67, 5.67, 5.67, 6.67, 7.33, 7.67, 8.00; spoken (n = 21) 3.33, 4.33, 4.67, 5.67, 5.67, 6.00, 6.00, 6.00, 6.33, 6.67, 6.67, 6.67, 7.00, 7.00, 7.00, 7.00, 7.00, 7.67, 8.67, 10.00, 10.00. Means: written 4.649, spoken 6.636.

Methods. Student's t via t.test(var.equal=TRUE); Welch's via t.test(var.equal=FALSE); Wilcoxon via wilcox.test; Shapiro-Wilk on the deviations from group means; F test via var.test; Yuen and bootstrapped Yuen (20% trim, 1000 samples) via the WRS2 package (yuen, yuenbt).

Agreement. Seven of the eight reported statistics reproduce to the paper's rounding exactly (Student's t, Welch's t, Wilcoxon, F test, Yuen's, and the power estimate). The two remaining are minor and non-load-bearing: the Shapiro-Wilk p-value reproduces exactly (p = .124) while the reported W = 0.966 differs slightly from the recomputed 0.9553; and the bootstrapped Yuen p-value is stochastic (paper .002; recomputation is seed-dependent in .002–.004, as the paper's WRS2 0.10-0 bootstrap algorithm differs from the installed version). Neither changes any conclusion: normality is not rejected (p = .124), the variance assumption is not rejected (p = .458), and all four strategies show a significant difference favouring the audio group.

Load-bearing claim. The paper's central practical claim - that the decision-tree (Strategy 1) approach is feasible for this example and that all four strategies identify the same significant effect - reproduces exactly.

Advisory items

  • ADV-001 (P3). The Shapiro-Wilk W statistic is reported as 0.966 but recomputes to 0.9553; the p-value (and hence the conclusion) is unchanged.
  • ADV-002 (P3). The bootstrapped Yuen p-value is not reproducible to the exact decimal because the bootstrap algorithm differs across WRS2 versions and is seed-dependent; the reported 95% CI is not returned by the installed WRS2 version. The conclusion is unaffected.
  • ADV-003 (P3). The power estimate of "33%" corresponds to the actual unbalanced design (n = 18, 21); a balanced n = 18/group calculation gives ~31%, so the figure is design-specific.
