An unusually clean submission, reconfirmed by independent regeneration. Every load-bearing quantitative claim reproduces exactly from the shipped results table: the false-positive counts (ANOVA 304, GLMM 341, BGLMM 304, PP 2, meta-BGLMM 1), the effect-size→probability mapping (0.5, 0.62, 0.73, 0.82, 0.88; e=2 → +0.38), the ANOVA underestimation as between-individual variance grows (e=2: 0.381 → 0.345), the near-identity of posterior passing to the pooled "meta-BGLMM" (cor = 0.9999, mean |diff| = 0.0097), and BGLMM ≈ GLMM under minimally-informative priors (mean |diff| = 0.0055). Crucially, the re-audit additionally reproduced the method itself from scratch: a fixed-seed R simulation of the DGM + ANOVA + GLMM gave ANOVA FP 5.33% / GLMM FP 5.75% (paper ~5.07%/5.68%) with the same ANOVA-underestimation and TPR patterns; a Python cross-check independently returned 5.42%; and a from-scratch Bayesian posterior-passing run confirmed BGLMM ≈ GLMM, PP convergence to the true effect within ~5–15 experiments, and PP ≈ pooled analysis. The core contribution — posterior passing recovers the true population effect with near-meta-analytic accuracy and far fewer false positives than one-shot ANOVA/GLMM — is fully supported. The one P2 (ADV-001) is that the exact MCMC draws are not regenerable byte-for-byte (no recorded RNG seed; JAGS/Stan unavailable on this host); the three P3s are documentation/clarity items. No primary statistic is affected.

Findings (for the authors)

P2 — medium

ADV-001 — The exact MCMC simulation is not regenerable byte-for-byte (no recorded seed; JAGS/Stan unavailable). All reported counts are reproduced exactly from the author's shipped results table Results/meta_results_18_09_16.txt, and the method is independently validated from-scratch (this audit). But a third party cannot reproduce the exact table from scratch: main.R ships no set.seed(), and JAGS is not installed (Stan/brms cannot compile without Rtools/make). The specific numbers are trustworthy (author's own run, matching the paper) and the behaviour is now independently confirmed; what remains is exact regenerability. Fix: record the RNG seed and JAGS/rjags/lme4 versions; ship a "smoke-test" that runs one (e,var) combo end-to-end in minutes.

P3 — low

ADV-002 — "Converges within 10–15 analyses" is not in the shipped summary, though now behaviourally supported. The shipped table logs only the final-experiment PP value (pp_final_expt_only=TRUE; util.R:229-234). The from-scratch PP trajectory in this audit supports convergence well within 60 experiments (consistent with 10–15), but the exact figure is still not checkable from the shipped artifacts. Fix: ship the per-experiment PP trajectory (set pp_final_expt_only=FALSE) so the exact convergence rate is verifiable.

ADV-003 — The "positive result" decision rule differs by method (not flagged); random effect unidentified at var=0. In analyses.R the GLMM/BGLMM/PP/mega branches set p-values to NaN, so their "positive" is defined by the 95% CI/credible interval excluding 0 (util.R:309-329); only the ANOVA uses p<.05 (util.R:305-307). The headline PP-vs-others comparison is unaffected, but the cross-method TPR mixes decision rules. Separately, at var=0 the participant random effect is unidentified (the DGM has no between-participant variance), producing lme4 boundary/singular fits — a transparency note. Fix: state the per-method "positive" rule in the methods; note the var=0 random-effect degeneracy.

ADV-004 — Three declared variance parameters are inert no-ops (undocumented). main.R (lines 28-30) declares var_sexs/var_conds/var_sex_conds with a comment that they "do not currently do anything!"; simulation.R uses only var_base. The varied parameter is correctly the baseline-performance variance; results unaffected, but the dead parameters could mislead a re-implementer. Fix: remove (or wire up) the inert parameters and add a one-line note about var_base.

What this audit does not guarantee

  • The exact JAGS MCMC draws were not re-run. JAGS is not installed and Stan/brms cannot compile on this host (no Rtools/make). All numbers were (a) reproduced exactly from the author's shipped results table and (b) re-derived from an independent from-scratch reimplementation (R DGM+ANOVA+GLMM; a custom Polya-Gamma Gibbs sampler for BGLMM/PP; Python cross-check). A byte-for-byte JAGS reproduction of the exact table remains impossible without the unrecorded seed — this is ADV-001.
  • The "converges within 10–15 analyses" figure (ADV-002) is not quantified in the shipped summary; it is supported directionally and behaviourally by the from-scratch PP trajectory but not independently recomputable to the exact number.
  • Background literature claims (the seven stereotype-threat meta-analyses, Open Science Collaboration statistics) were not part of the audited statistical pipeline.
  • The independent from-scratch FP counts (5.33%/5.75%/5.42%) are single-sample binomial realisations under a fixed seed chosen by this audit; they confirm the paper's ~5% rates and cross-method ordering but are not expected to equal the author's exact counts (no shared seed).
