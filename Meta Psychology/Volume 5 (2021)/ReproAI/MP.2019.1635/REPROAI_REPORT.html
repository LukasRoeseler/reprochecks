Reproduction detail

Data. Marsh_2018_raw_means.csv (proportion correct per subject per task) from OSF project xds8g. Columns: subject, task (SR-low, SR-high, MI), quiet, neu, pos, neg. Read with read_csv2 (semicolon-separated, comma decimal).

Operationalization. Speech effect = quiet minus neutral; emotion effect = neutral minus mean(positive, negative). The direct analysis compares the two tasks SR-high (high load serial recall) and MI (missing-item) on these difference scores.

Methods. 2x2 mixed ANOVA via ezANOVA (type = 3; task between-subjects, effect within-subjects); between-subjects t-tests of task effects via t.test(x, y, paired=FALSE); Bayes factors computed with Dienes's functions (BF_U uniform, BF_t half-normal and t-distributed), using the observed speech effect (0.061) to define the alternative hypothesis.

Agreement. Every reported statistic reproduces to the paper's rounding exactly: interaction F(1,127) = 12.53, p < .001; speech task effect 0.061 [0.014, 0.107] p = .011; emotion task effect -0.062 [-0.095, -0.029] p < .001; speech-emotion contrast 0.123 [0.054, 0.191] p = .001; BF01 = 12.50 (uniform) and 16.67 (half-normal), with the t-distributed prior giving 14.29 (inside the reported 12.5-16.7 range). The conclusion that the data support a dissociation (crossover interaction) is confirmed.

Advisory items

  • ADV-001 (P3). The reanalysis uses preprocessed (subject-level mean) data shared by the original authors, not raw trial data; the reproduction therefore validates the reanalysis pipeline but not the underlying raw-data processing.
