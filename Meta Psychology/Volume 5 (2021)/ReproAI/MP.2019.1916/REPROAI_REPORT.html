Verdict summary

This is a clean reproduction of the paper's worked example. The article's central illustrative claim - that a Student's t test on ordinal data produces different results depending on the (arbitrary) coding rule used, whereas the Mann-Whitney U test is invariant across monotonic transformations - reproduces exactly from the paper's own example data.

Reproduction detail

Data. Pet owners: Hakim (very satisfied), Jeff (moderately satisfied); non-owners: Sarah (moderately dissatisfied), Ming (very dissatisfied). Coding rule one: very dissatisfied = 1, moderately dissatisfied = 2, moderately satisfied = 3, very satisfied = 4 (pet [4, 3]; non-pet [2, 1]; mean diff = 2). Coding rule two: very dissatisfied = 0, moderately dissatisfied = 1, moderately satisfied = 1000, very satisfied = 1002 (pet [1002, 1000]; non-pet [1, 0]; mean diff = 1000.5).

Methods. Student's t via t.test(var.equal=TRUE); Mann-Whitney U via wilcox.test.

Agreement. All four reported statistics reproduce to the paper's rounding exactly: rule 1 t(2) = 2.83 (p = .106), rule 2 t(2) = 894.87 (p < .001), and the Mann-Whitney U p = .33, identical across both coding rules. The article's central point - that parametric statistics on ordinal data are coding-rule-dependent while rank-based tests are invariant - is demonstrated exactly as reported.
