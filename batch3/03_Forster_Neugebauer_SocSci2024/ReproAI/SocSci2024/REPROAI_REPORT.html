Findings (for the authors)

P3 — low

ADV-001 — Table 2 FS occupational-field proportions do not follow strict 2-decimal rounding. The raw FS field counts reproduce exactly (512/560/1944/824). The printed proportions of 0.13/0.15/0.50/0.22 differ from strict 2-decimal rounding of 0.1333/0.1458/0.5063/0.2146, which would read 0.13/0.15/0.51/0.21. Administration is printed 0.50 against 0.5063, and Media 0.22 against 0.2146. The choice appears designed to force the column to sum to 1.00 (same for the FE panel, 0.22/0.13/0.42/0.23, which happens to round cleanly). This is a presentation/rounding choice only; it does not affect any model, effect, or conclusion. Fix: print 0.51 and 0.21, or annotate the column as rounded-then-summed to 1.00.

ADV-002 — README and .do-file headers reference stale data file names. readme.txt and the header comments of 00_master.do/01_dataprep_significance.do name the data as validation_replication_fe.dta / validation_replication_fs.dta, but the shipped files are validation_fe.dta / validation_fs.dta. Not load-bearing: master.do only sets directory globals and every analysis .do opens the correct shipped names. Fix: align README/header comments with the actual archive file names.

ADV-OBS-003 — type_applicants carries missing codes (−998, −949) in the FS data (observation). 56 rows each are coded −998/−949. The shipped robustness code and the manuscript's 61% figure both use the full 3,840 denominator (threshold 3|4 → 0.6104), so no discrepancy arises. Noted only so future users are aware of the flagged non-response rows. Fix: none required; optionally document the codes in a data dictionary.

What this package already does right

  • Genuinely open and complete. Sociological Science's open-access policy plus a single, current OSF replication package (node x2tcp) ships both datasets (FE + FS), all analysis code, and a clean README. The preregistration (node 2jrgu) is public and matches the study.
  • Data and code are mutually consistent and reproduce the manuscript exactly. Every headline statistic regenerates in R to the manuscript's own reported precision — reflecting well on the analysis pipeline, not merely a final-tidy copy.
  • Clean provenance / deterministic pipeline. No RNG anywhere; closed-form OLS; outputs stable across runs. No PII was found in the shipped data (only anonymised employer IDs and coded covariates; no free-text fields were shipped).
  • Honest reporting of the null/negative result. The reproduced numbers genuinely support the central cautionary claim that the factorial survey fails to reproduce the field-experiment discrimination effect across all sensitivity/effort subgroups.

What this audit does not guarantee

  • No live Stata execution. Stata is not installed on this host; the authors' .do files were not run. All numbers were independently regenerated in R from the raw .dta to the manuscript's reported precision and MDS match the authors' model logic, but a byte-for-byte Stata run was not performed. If desired, running 01_code/*.do in Stata 18 and diffing the regenerated 03_tables/04_figures/05_logs against the paper would close this residual gap (offered as optional cross-validation, not a requirement).
  • Full online-supplement coefficient matrices (Tables S7–S10/S11–S19) were not diffe'd cell-by-cell. The headline rows reproduced here (the FE/FS main coefficients, the two disparity interactions, all subgroup size and descriptive figures) are the load-bearing entries and all agree; a complete spreadsheet-level diff of every supplement table was out of scope.
  • Preregistration content was confirmed to exist publicly but its internal content was not diffed against the reported analyses (the article-level reproducibility of the results, not preregistration-adherence auditing, is the object of this check).
  • No live rendering of Figures 3–6 from the author's coefplot code was produced; the underlying point estimates and CIs they plot are all reproduced numerically here instead.
