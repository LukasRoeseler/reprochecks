To reproduce the analyses presented in the paper: "Forster, A.G. and M. Neugebauer (2024). Factorial Survey Experiments to Predict Real-World Behavior: A Cautionary Tale From Hiring Studies" follow these steps:

1. Open 01_code —> master.do in Stata
2. Within master.do customize the file path to the location on your computer where this replication package folder is located.
3. Execute the master do-file in Stata
4. The tables and figures for the data analyses are placed in 03_tables and 04_figures. In 05_logs you will find a log file with all Stata output
