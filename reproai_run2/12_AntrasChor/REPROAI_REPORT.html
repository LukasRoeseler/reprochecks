1. Data sourcing

The OSF hint q4cgv resolved via the OSF API v2 to a file GUID inside reproduction node qk9v3 ("Antràs_Econometrica_2013_a2Yx - Szabelska - Reproduction (with author data & code) - 28m96"), with children Data (my6bg), Analysis (zxdca), Methods/Materials, Audit/QA, etc. All files were downloaded:

  • Audit/QA: 28m96_audit1.csv.

Critical gap: The single dataset used by every headline table — USIOrelatedparty.dta (which feeds the dependent variable imp_intrafirm = imp_rel/(imp_non+imp_rel) and the tot_imp weights) — is not in the OSF Data component, and the Table2.do/Table3.do/Table5.do/Table7.do scripts are absent. The transparency trail confirms the intended reproduction rests entirely on that one file. It is derived from confidential U.S. Census Related-Party-Trade data; the author-hosted copy was blocked (HTTP 403/503) from this environment, has no Wayback capture (CDX empty), and no public mirror was found. Hence the dependent-variable file is unobtainable here, which prevents an independent re-run of the headline regressions.

The human transparency trail states that, working from USIOrelatedparty.dta downloaded from the author's site (27 Jan 2022) and after manual STATA code fixes (deleting semicolons, fixing working directory, re-lining commands, installing outreg2), Tables 3, 4, 5, 6 and 7 all reproduced exactly (focal coefficient –0.196, N=2,783), i.e. the claims were numerically reproducible once the full author data was in hand. The final audit sheet 28m96 nonetheless records values_match=Yes, repro_possible=No with no explanation, and the OSF package as shared is incomplete.

5. Findings & severity

IDSeverityFinding
F1P1OSF reproduction package is functionally incomplete: USIOrelatedparty.dta (the only dataset used by every headline table) and Table2/3/5/7 .do files (plus intermediation.dta, rulelaw.dta) are absent from the OSF nodes. A third party cannot re-run the headline tables from the shared package alone.
F2P2Code is not push-button: hardcoded author working directories, set memory 400m, # delimit ; syntax (semicolons removed for Stata 14), multi-line commands, dependence on external outreg2/areg — manual intervention required before any table reproduced.
F3P2Shipped downstreamness.dta contains stale/inconsistent precomputed interaction columns (M1/M2/…×duse_tuse/downmeasure) that do not equal duse_tuse × (median-split sigma indicator); code recomputes them, so headline result unaffected, but shipped data are internally inconsistent with IOsigmas.dta.
F4P3Documentation inconsistency: audit CSV says values_match=Yes yet repro_possible=No with no note, while the transparency trail reports exact reproduction of Tables 3–7 — ambiguous record of the reproduction outcome.

6. Verdict

Grade: NODATA. The headline OLS coefficients (focal claim: β1=–0.196, β2=0.171, N=2,783, and all companion tables) could not be independently re-computed because the single dataset carrying the dependent variable (USIOrelatedparty.dta) is missing from the OSF package and is effectively unobtainable in this environment (confidential Census-derived data; author site blocked; not archived; no mirror). No headline number was independently reproduced here, and no numbers were fabricated.

This agrees with the human FLoRA "computational issues" verdict: the reproduction is not standalone — it requires the author-side data file (acquired externally) and substantial manual code fixes. Supporting evidence is nonetheless strong: published values match the claims exactly, the complements/substitutes median-split logic verifies perfectly in the backable data, and the documented human attempt reproduced all headline tables to exact precision once the full data were in hand. The headline claim is therefore highly likely numerically reproducible, but it could not be independently confirmed from the OSF-shared materials.
