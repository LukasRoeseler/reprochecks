Push Button attempt
There are 23 STATA code files however this project only requires reproducing Tables 3, 4, 5, 6 and 7 therefore only files titled Table3.do, Table4.do, Table5.do, Table6.do and Table7.do will be used (they will all be Version ID 1 in OSF’s version control system). All code used only USIOrelatedparty.dta dataset. The analyst uses STATA 14.
In all code files initial commands not related to reproducing tables were removed and working directory changed manually to match the one on analyst’s computer. Also, all semicolons were deleted as they do not work within STATA 14. At this point tables 3 and 4 reproduced without any further intervention. Corresponding files were saved and uploaded to the OSF as Version ID 2 of corresponding documents.
Additionally, in Table5.do the local mergelist "downstreamness IOsigmas factorintensities randdintensity dispersion" as well as all commands starting with areg or outreg2 had to be moved to just one line (it is also possible that outreg2 must be installed first on computers that do not have this STATA package installed already). At this point table 5 was reproduced and the code file was saved and uploaded to the OSF as Version ID 2.
Table6.do and Table7.do were modified in the same way (commands that were spread over more than one line were brought together to form one line). At this point table 6 and 7 was reproduced and the code file was saved and uploaded to the OSF as Version ID 2.
This is the final analysis performed – all claims were tested.

Coded claim 4 text (original paper): “Following the guidance of our theoretical model, we run our benchmark specification from equation (32) in column 2, which includes the interactions of DUse_TUse with our proxies for the sequential substitutes (Elas &lt; Median) and complements (Elas &gt; Median) cases, as well as a dummy variable for the sequential complements case. The empirical results here are indeed strongly supportive of our model’s central prediction: The effect of downstreamness is positive and significant at the 5% level when the average buyer demand elasticity is above the median for this variable (Beta_2 &gt; 0), consistent with a greater propensity toward the integration of input suppliers that enter further downstream in the value chain.
