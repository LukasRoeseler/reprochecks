1. Study & headline claims

The study analyzes over 12,000 randomized controlled tests of online news headlines (Upworthy.com archive), testing whether the proportion of negative/positive words in a headline drives click-through rate (CTR) via a multilevel binomial model. Two central claims:

#ClaimReported value (p.814)Status
C1 Larger proportion of negative words increases CTR (main claim) β=0.018, SE=0.003, t=6.942, p<0.001, 99% CI=(0.011,0.025) (random-slopes model) Direction + significance confirmed
C2 Larger proportion of positive words decreases CTR β=−0.017, SE=0.003, t=−6.589, p<0.001, 99% CI=(−0.023,−0.010) (random-slopes model) Direction + significance confirmed

2. Data & code obtained

  • Analysis dataset: blind_regression_df.csv — 53,755 rows, 12,473 clickability-test clusters, model inputs (clicks, impressions, positive, negative, length, complexity, platform_age) complete, no NAs.
  • Replication report (I4R, Reiss & Roggenkamp, Dec 2024): report.txt/.pdf — documents blind + unblind reproduction, LLM robustness checks.
  • Authors’ response: NHB_response.txt/.pdf — confirms exact reproduction of key results.
  • OSF reproduction node bfhdw identified; scripts folder (01 Preprocessing.R … Report_Supplementary.Rmd, utils_*.R) and Data folder enumerated via OSF API v2.
  • Incomplete in package: LIWC2015 dictionary (proprietary, not shared), raw Upworthy file (hosted on Matias et al.), one topic-modeling file (missing by mistake).

3. Independent recomputation (this audit)

Multilevel binomial (logit) GLMM, clusters = clickability_test_id, lme4 v2.0.6, R 4.6.1, via rerun_models.R. Two specifications:

Both claims are highly significant in the predicted directions. The rerun data are the I4R blind reconstruction (no stemming), so the negativity magnitude (≈0.008–0.009) intentionally differs from the paper’s final analysis numbers; it matches the I4R “blind without stemming” columns of their Table 3.

6. Verdict

Grade: CONSISTENT. The human FLoRA claim is computationally reproducible — this audit’s verdict matches the human assessment: using the authors’ code and data the key results reproduce with numerically identical values (I4R unblind reproduction), and an independent rerun confirms both headline claims in direction and significance at p<0.001. Grade stops short of FULL only because the exact main-claim magnitude is not recoverable from the local blind-reconstruction dataset without the authors’ stemming step.

No numbers fabricated; all figures above come from the local rerun (_rerun_models_out.txt) or cited sources.
