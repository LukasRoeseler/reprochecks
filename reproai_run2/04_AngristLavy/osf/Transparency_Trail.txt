Push Button attempt
This is the very first attempt to reproduce the analysis using the provided materials “out of the box”, i.e., without any changes. We call this a “push button” reproduction as the goal is that you can effectively push the “Run” button and produce the desired output.
The data and code were made available by the author on OSF. The code was provided as a do-file and the data were uploaded in Stata format (.dta). First, Stata 16.0 was initialized. Next, ‘table-2.do’ was loaded and the working directory was changed to save the results and output in the same folder as the do-file and the dataset. One issue faced while running the do-file was that an error message popped up since the command ‘brl’ went unrecognized and the do-file could not be executed. So, the package ‘brl’ was installed, the do and help files were stored in the Stata working directory and the do-file was run without any errors or breaks. Then, the output table generated by Stata after running the do-file was used to evaluate the claims associated with Table 2. Next, ‘table-4.do’ was loaded and the working directory was changed to save the results and output in the same folder as the do-file and the dataset. This time, because the ‘brl’ package was installed, the do-file was executed without any errors or breaks and the claim relevant to Table 4 was evaluated using the output table generated once the do-file was run. 
For Table 8, we used data and code made available by the authors on OSF under the file “table-8.rar”. Files from this archive were used to reproduce the focal claim 2l95y4. Of the four programs, the SAS program “table8_linear_quart.sas” was opened in SAS 9.4 and the working directory was changed as per the readme file instructions (“ReadmeTable8.txt”). The dataset “base_ns.sas7bdat” was loaded in SAS and then the program was executed. The resulting output generated was stored and only the results corresponding to the focal claim were copied into a separate MS Word document for ease of locating results (“angrist_sas_ols.docx”).
One issue encountered was that Stata 16.0 failed to recognize the command ‘brl’, resulting in an error when the do-file was executed. Therefore, the package ‘brl’ was installed from https://economics.byu.edu/faculty-and-staff/frandsen/software after enlisting some help from https://www.statalist.org/forums/forum/general-stata-discussion/general/1337175-installing-an-ado-file-in-stata. The do and help files associated with the ‘brl’ package were stored in the Stata working directory and the do-file was run without any errors or breaks. Then, the code was executed exactly as provided without the need for further modification.
