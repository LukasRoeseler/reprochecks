Grade: FULL (data obtained; every headline number independently reproduced; flagship standard error reproduced exactly).

This is a fully numerically reproducible economics RCT. From the authors' own raw Israeli Ministry-of-Education administrative data I independently reproduced — in Python and from scratch — the paper's central finding: the Achievement-Awards treatment raised 2001 Bagrut (matriculation) certification among girls by ≈0.105 (10.5 pp) in the fully-controlled OLS model, with the paper's reported BRL standard error of 0.047 reproduced exactly (independent implementation of the Bias-Reduced Linearization routine from brl.ado → 0.0472902). The "no effect on boys" result also reproduced exactly (girls 0.1047457 vs paper 0.105; boys −0.022174 vs paper −0.022). Logit marginal effects reproduce exactly (girls 0.097→0.097374; boys −0.023→−0.023381). Table 4's headline (girls in the top half of the lagged-score distribution +0.206) reproduces exactly (marginal effect 0.2058262, N=933). Table 8's college-attendance effect for top-quartile girls (0.086, SE 0.055) reproduces to 0.08545 (robust SE 0.0557, N=921). The human push-button reproduction previously reproduced all five focal claims exactly; this audit replicates them independently. Only two P3 (minor friction) findings: dependence on the external brl package and hard-coded absolute Windows working directories.

BRL SE — independent implementation detail

The flagship SE (girls OLS, full controls, 2001) is reported as 0.047. I ported the calcbrl Mata routine from the authors' brl.ado (bias-reduced linearization = leverage/HC2-style adjustment of the cluster sandwich with a Satterthwaite df). Result: 0.0472902036, i.e. the exact figure in the reproduction output (t2_levels_estimates_NDM.dta = 0.0472902) and the paper's 0.047. This is a precise, independent match of the headline standard error, not merely the coefficient.

Findings (for the authors / reproducers)

P3 — low

ADV-001 — Replication depends on the third-party brl (Bias-Reduced Linearization) package, not bundled with the paper's code. Running table-2.do on stock Stata errors immediately (command brl unrecognized); the analysts had to install brl.ado from Byron Frandsen's site. The package is available and was mirrored on OSF, so the barrier is low; the human PBR produced exact results after install. Confirmed by this audit to be analytically correct (the BRL SE matches the paper exactly).

ADV-002 — Hard-coded absolute Windows paths and an output-erasing command in the analysis programs. The do-files/SAS contain cd "W:\Student bonuses\Yannay Aug 08\data" and the do-files end with cap erase ..._estimates_NDM.dta, which deletes the primary output tables at the end of each run (the PBR curators had to stop execution before this line). No numerical impact; mild reproducibility friction.

What this audit confirms / does not do

  • Confirmed: the RCT headline (girls +~0.105 Bagrut, significant; boys no effect) and the subgroup/college claims. All point estimates reproduce to the reported 3-decimal precision; the flagship BRL SE (0.047) reproduces exactly with an independent implementation.
  • Not re-derived here: the logit BRL SEs (reported 0.046/0.045) and the Table 8 SAS empirical robust SE (0.0546) use the weighted linearization variant of BRL; their point estimates are verified and their SE magnitudes are consistent with the paper (girls logit effect 0.097/0.046 ≈ t 2.1 "marginally significant", matching the paper's wording). The human PBR previously reproduced these exact SEs, and no discrepancy with them exists in any artifact.
  • No raw-confidentiality limitation: the full administrative dataset was shared on OSF and used end-to-end — this is a textbook positive example for a 2009 AER paper.
