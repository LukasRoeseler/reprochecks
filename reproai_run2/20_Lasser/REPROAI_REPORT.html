Data sourcing & reproduction inputs

Paper full text obtained from PubMed Central (PMC10730411, CC-BY). The FLoRA reproduction project (OSF f5p78, Münster Replication Games: Brummernhenrich, Feistauer, Eickmann & Vaporova) holds the replication report and the authors’ response, which were read to understand prior findings and to identify the source-data location.

The authors’ open reproduction package (OSF vny8k + GitHub JanaLasser/new-ontology-of-truth) was used to independently re-compute the headline claims:

  • data/users/users.csv → Welch tests (temporal dynamics)
  • data/tweets/tweets_for_lme_modelling_NG.csv → tweet-level LME (headline “12.8-point” claim), 504,809 rows
  • data/articles/articles.csv.gzip → article-level OLS, N=261,765
  • Model code read from code/analysis/lmer_models_tweets.Rmd and OLS_regression_articles.ipynb

Important: The human FLoRA could not run the LME because the two files tweets_for_lme_modelling_NG.csv and tweets_for_lme_modelling_independent.csv had been removed from the OSF repository (11 Mar 2023). The authors restored them on 02 Feb 2026, so by the time of this independent audit the data were obtainable and the headline model could be fitted end-to-end.

Computational re-run notes

LME (C5/C6): fitted in R 4.6.1 using lme4/lmerTest with the exact formula from lmer_models_tweets.Rmd: NG ~ belief*truth + belief*truth*party + (1 + belief*truth|author_id), control bobyqa, maxfun=30000, baseline = Democrat, N = 504,809 (matches paper).

OLS (C7): statsmodels 0.14.1, formula NG_score ~ avg_belief_score + avg_truth_score + party + party*avg_belief_score + party*avg_truth_score + party*avg_belief_score*avg_truth_score, filtered to party_count==1 + dropna → N=261,765 (matches paper).

Headline derivation: the “12.8-point” figure equals the belief×Republican interaction coefficient (−0.128) expressed as NewsGuard points (0.128 × 100). This coefficient, its standard error and 95% CI all reproduce.

Findings (severity)

P2Figure 2 caption sample-size inconsistency. The caption reports “2011–2013: 331 Democrats and 514 Republicans; 2019–2022: 295 Democrats and 494 Republicans,” but the data actually contain (per tests that reproduce exactly): early 331 D / 295 R; late 514 D / 494 R. The paper’s own reproduced Welch degrees of freedom (558/493/516/483) confirm the users.csv composition, so the caption’s per-party/period counts appear swapped. Cosmetic-to-minor; no reproduced statistic is affected.
P3Component naming inconsistency. “Fact speaking” (paper) is stored/variable-named “truth” (avg_truth_score) in the data and code; reproducibility documents flag the same. Cosmetic.
P3 (context)Full end-to-end raw pipeline not reproducible without restricted data. Tweet texts (data-protection), proprietary NewsGuard labels and NYT abstracts cannot be shared; Figure 1 and raw-data regeneration require them. This is a documented, disclosed limitation and does not affect reproduction of any headline statistic, all of which used the shared analysis-ready files.

Verdict

Grade: FULL. All headline numerical claims were independently reproduced exactly from the authors’ open data and code: the temporal Welch tests (belief/fact-speaking increases for both parties), the tweet-level linear mixed-effects model underpinning the flagship “10% belief speaking → −12.8 NewsGuard points” effect (interaction = −0.128, CI [−0.146, −0.111], N=504,809), and the article-level OLS (N=261,765). No headline claim was contradicted.

vs human FLoRA (“technical failure”): The human reproduction reported a technical failure only because the LME input files had been deleted from OSF at the time it ran. The authors restored those files on 02 Feb 2026. This audit obtained them and successfully re-ran the LME, so its headline claim is verified — the difference from the human verdict is due to data availability at run time, not to any flaw in either analysis. The residual issues (raw-tweet/NewsGuard/NYT access restrictions) are disclosed data-protection limits rather than reproducibility errors in the headline results.
