Please not that the analyst used STATA 17 and some earlier versions can have issues when generating as many variables as the code instructs (the authors set maxvar to 12000, and earlier version are limited to lower numbers, ie. STATA 14 can only accommodate ~ 2500 variables). Additionally, each table can take a lot of time to be reproduced (~1-2 hours each on HP-ENVYx360, 2.10 GHz, 8.00 GB RAM)
All claims were tested and this was the final analysis performed.
