Push Button attempt
The data and analysis scripts were provided to me by the SCORE team, who had obtained them from the original authors via uploading the data to their Github repository. The analysis scripts were separated out into 6 r files: 1 x preprocessing script, 1 x bespoke analysis functions, 1 x script for analysis of experiment 1 data,  1 x script for simulation of experiment 1 results,  1 x script for analysis of experiment 2 data,  1 x script for simulation of experiment 2 results. There were an additional 4 .stan files for bayesian analysis functions. 
The data provided in the folders had already been pre-processed (no raw data available but inferring from the preprocessing script no material changes were being made aside from tidying up the individual files and combining),
Running the original scripts as provided caused an error: x could not find function "revalue" and as such I could not run the analysis exactly out of the box. 

Analysis attempt 1
I edited the script as follows: 
- Needed to add two lines at front of the analysis_exp1.r: script to load packages "plyr" and "tidyverse"
- Created a figures folder for the script to save figures in appropriate directory
- Needed to amend the location of file saves from "../doc/journal/" to "figures"
-changed height (5 in to 6), width (8 in to 10) and resolution (from 200 to 300) of figure exports to improve visibility 
- corrected two typos missing " in figure export lines
- specified the package for all instances of function summarize so that it calls dplyr. 

Using this revised version (“analysis_exp1_round1.R”) I was able to execute the analysis that tested all five claims. 
The output is saved as a .RData file for confirmation.

Analysis attempt 2
Further edits were made to the code so that results (mean values for each condition and confidence interval differences) could be saved as objects printed to the console and easily read for the purposes of evaluating the claim. Where appropriate, decimals were multiplied by 100 for percentages, again for ease of reporting for this document. 
In this analysis attempt, all 5 claims (IDs: m8lkk9, g44qqk, m5xkkr, myjqqn, b2vooo) were able to be tested.

Analyst success criteria: All outcomes meet the Approximate Reproduction Criteria. Note that there is a potential reporting error here in the manuscript. The authors report that the difference between the two groups did not lie outside the credible interval, but the values they report show that the credible interval does not include zero, which would indicate that there are differences. Following discussion with Priya Silverstein, we are using the authors reported values, the CI minimum for the approximate reproduction &lt;=.07 (includes CIs that include zero, but also CIs that match with the actual reported minimum, to cover both bases)
Reproduction outcome: Based on these criteria, the claim did reproduce.
Discussion: The complexity of the claim was discussed at an earlier stage- see the justification above about the potential reporting error.
