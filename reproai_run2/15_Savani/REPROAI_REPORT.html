1. Data sourcing

The registry OSF hint osf.io/f5vne is a file download GUID (the SCORE push-button reproduction report), not a project node. The real FLoRA reproduction project was resolved via the OSF API: the SCORE project qpemg ("SCORE - Savani_PsychologSci_2010_88xa"). Materials used:

  • Author data: Data by Subject KS.xlsx (128 rows; 60 U.S., 68 Indian; columns culture, cond, gender, age, numactions) — author-provided summary of button presses.
  • Raw trial data: Data by Trial.xls (DirectRT output, 4291 button-press rows).
  • Author analysis code & log: Savani_PsychologSci_2010_88xa.do & .log (Stata anova numactions culture##cond + esize).
  • SCORE docs: push-button reproduction report (Talbert), extracted RRP text, bushel-trace claims, author correspondence, reproduction README.

Data provenance: The focal reproduction claim (Study 3) was the Culture × Condition interaction. The author's correspondence disclosed unexplained discrepancies between the paper's SPSS F-values and his own Stata re-analysis ("same results in terms of statistical significance but not in terms of the F-values"), and that video data were missing for one Indian participant (excluded; 67 valid Indian).

2. Headline numerical claims (Study 3, the target)

  1. 2×2 ANOVA: main effect of culture F(1,120) = 14.79, p < .005, d = 0.55.
  2. Main effect of condition F(1,120) = 11.56, p = .01, d = 0.47.
  3. Culture × Condition interaction F(1,120) = 5.69, p < .02, p_rep = .96.
  4. Simple effects: control condition t < 1 (cultures similar); construal-of-choice condition Indians fewer actions, t(32) = 4.25, p < .001, d = 1.03.

4. Findings & severity

  • P2 — Reported ANOVA statistics do not reproduce exactly. The focal interaction reproduces only approximately (F 5.69 → 6.12 with df 120 → 123); main-effect F's differ more (culture 14.79 vs 10.18; condition 11.56 vs 7.42). All remain significant in the same direction. Author explicitly disclosed the F-value discrepancy between SPSS and Stata; did not affect conclusion.
  • P2 — Degrees-of-freedom mismatches vs the data. Paper reports F(1,120) but the actual analysis uses df(1,123); the simple-effect t is reported as t(32) vs the actual two-sample df = 65. SCORE text-tagging flagged "DF reported in analysis may disagree with stated sample size."
  • P3 — Minor effect-size/rounding nuances (paper d = 1.03 vs computed 1.014; d = 0.55/0.47 for un-reproducible main effects).

5. Verdict

Grade: CONSISTENT. The author's data and code were obtained and independently re-run. The qualitative, focal claim of the paper — that U.S. Americans construe more actions as choices than Indians, driven by the choice condition (a significant Culture × Condition interaction in the same direction) — is robustly reproduced. However, the exact headline statistics (F-values, dfs, and the t-test df) do not reproduce from the shared data. This matches the human FLoRA classification "computational issues" precisely: significance and direction hold, but the reported numbers are not exact, with an acknowledged historical software discrepancy and df inconsistencies. Not FULL (numbers not exact) and not FAIL (nothing contradicted).
