5. Findings & severity

IDSeverityFinding
F1P2Cross-file data inconsistency: subject 5-16 is coded choice=1 (early) in STATA_data.xlsx but resolution=3 (indifferent) in the raw inputs.xls. Consequently the paper's descriptive "61 of 101" matches the analysis file's choice count, while the raw input sheet and the regression DV early (sum=60) give 60. Provenance of the shipped analysis file is partly untied to the raw data.
F2P2Full computational chain is not push-button / not self-contained: the posterior-probability regressors (type1-4_post/early_post) that drive every Table 5 result are author-supplied columns in STATA_data.xlsx and are not regenerated by the shipped MATLAB code (quick_estimates.m never writes Excel; make_boots.m/generalized_EMscript_forboots.m fail on the platform-dependent xlswrite; STATA commands.do has hardcoded author paths and a missing EWreg dependency). Numbers recover from the shipped file, but the estimate-to-data chain cannot be independently re-run end-to-end.
F3P3Paper-internal inconsistency on the "68%" classification claim: main text states 68% are types 3 or 4, but the paper's own Table 4 values (0.407+0.288) sum to 69.5%, and the shipped data yield 69.3%. Claim reproduces only approximately.

6. Verdict

Grade: CONSISTENT. Three of the four headline numerical claims (60.4% early-resolution majority; Table 5 OLS 0.2008457 (0.107769), p=0.065; Table 5 Erickson–Whited 0.50728 (0.014)) were independently re-computed exactly from the OSF-shipped data. The remaining claim (68% classified as early-preferring types) reproduces only approximately (69.31%), with a minor internal inconsistency already in the paper (68% text vs 69.5% from its own Table 4). No headline claim is contradicted.

This agrees with the human FLoRA "computational issues" verdict: the pipeline is not push-button or fully self-contained — the mixture-model posterior probabilities feeding the headline regressions are supplied in the Excel input rather than re-generated by the MATLAB code, and running the code requires fixing platform dependencies (xlswrite), hardcoded paths, and obtaining the external EWreg. However — matching the human SCORE trail, which found these exact same claims reproduced (3 precise, 1 approximate) — the actual headline numbers reproduce cleanly from the shipped analysis file. No numbers were fabricated; all values above were computed in this audit.
