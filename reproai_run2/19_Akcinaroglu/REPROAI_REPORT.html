3. Verification (independent re-computation)

Independent re-computation of the headline coefficient required running the competing-risks regression (stcrreg in Stata) on the author’s dataset with the covariate numberofrebels. This was not possible: the dataset is absent from the reproduction node and could not be located publicly. No regression could be run and no numbers were computed or fabricated in this audit.

Independent analysis status: blocked. The reproduced Stata .do script (akcinaroglu.do) was inspected: it depends on import excel using replicationdata and variable numberofrebels for every model block (peace agreements, rebel victory, government victory, attrition). Because the Excel data file and the key variable are absent, no model can be estimated. The only available quantified claim (0.64, SE 0.08, p < .01) comes from the paper itself as abstracted in the human SCORE report — it was not independently re-derived.
