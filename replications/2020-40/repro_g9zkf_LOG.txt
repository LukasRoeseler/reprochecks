METHOD (from runpca.m / createpreprocesseddata.m / PCAMV pca_full.m)
  - Bayesian (variational-Bayes) PCA with missing values (PCAMV toolbox, pca_full.m,
    algorithm='vb', maxiters=30, seed=2), applied to stacked normalized-score matrix
    X (36297 users x 51 games x 8 practice-stage bins = 408 columns).
  - Held-out validation: 1 game per user left out -> XTEST (196609 obs).
  - Metrics: cross-validated normalized absolute error (abserror), normalized RMSE,
    and variance explained (corr^4 as coded: corrcoef.^2 then ^2), for k=1..12 factors,
    plus a mean-learning-curve baseline.
  - Figure2.xlsx (archive) stores the paper's reported Figure2a values.

DATA
  - normalized_score_array_training.csv (6,090,727 obs): X matrix (long form).
    NOTE: its game_id is the ORIGINAL game row; must be reindexed via opt.whgames
    to the analysis column order. Verified == opt.XS (exact to float32 rounding).
  - normalized_score_array_validation.csv: only POSITIONS of held-out data; all
    scores are ' NaN' strings -> actual test scores taken from opt/XSTEST.
  - Data reconstruction validated: X non-NaN count 6,090,727 (== opt.XS);
    XTEST 196,609 (== opt.XSTEST); max abs diff 5e-5 (float32 rounding).

NUMBER OF LATENT FACTORS
  - The paper retains 6 latent learning factors (whdim=6 in runpca.m;
    Figure3.xlsx has 6 factors x 8 practice stages = 48 coefficient columns).
  - Cross-validated prediction error (Figure2a) flattens after ~6-8 factors:
    paper abserror_test plateaus near 0.438-0.441 (min 0.4382 at k=10);
    my curve flattens similarly (0.432-0.442).

  factor5 = 0.938, factor6 = 0.694.
