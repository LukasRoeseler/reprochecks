BLOCKER ASSESSMENT (Functions.R was never shipped)
  NOT truly fatal. Missing Functions.R contained only a small set of helper
  functions recovered/standard: zero1 (min-max to 0-1), get_lower_tri,
  get.desc, read.dta (haven), read.dta13 (readstata13). Reimplemented in
  work/d5g72/Functions.R.
  ACTUAL blockers in the shipped pipeline (all worked around here):
   (1) Main_Text_Results.R load("dataset_coded.Rdata") - this file is NOT in
       the archive; pipeline cannot run verbatim (needs coded objects built by
       first running the *coding*.R scripts in global env).
   (2) US_conceptual_coding.R genuine typo bug: Dlogeda_Dive uses column
       "logedab_Skydive_excitemen" (missing 't'). Protocol 1 creates double-t
       "logedab_Skydive_excitementt" while protocols 2/3 have single-t; the
       rbind() of Temple_study fails on unequal column counts. Fixed with
       dplyr::bind_rows + adding NA column.
