Findings (for the authors / journal)

P2 — medium

ADV-001 — The J2QGS/Submission copy of the analysis script no longer reproduces the published results under metafor 5.0.1. The analysis script shipped inside the paper's own OSF DOI project (J2QGS/Submission/872-DataAnalysis.R) uses hard-coded column indices to enter the Averbeck (2012) effect size that differ from the paper-cited copy (osf.io/kd3en) — adata[1,20 / 26 / 21 / 27] vs adata[1,19 / 25 / 20 / 26]. Run verbatim on R 4.6.1 + metafor 5.0.1, the J2QGS variant leaves SMD_post=NA and SMCR=NA for Averbeck and overwrites vSMD_post/vSMCR with −0.51; metafor silently drops that study (k=15) and the estimates drift: overall SMD 0.1986 (z=1.4586, p=0.1447, CI[−0.068,0.465]) vs reported 0.22/1.67/0.0953; overall SMCR 0.1479 (z=1.0451, p=0.2960) vs reported 0.17/1.23/0.217. The paper-cited kd3en copy reproduces every number exactly (k=16), so the published science is intact and this does not change any conclusion. Root cause: hard-coded column indices are sensitive to metafor::escalc()'s output column layout, which is version-dependent. Fix: replace the hard-coded indices with named-column assignments (adata$SMD_post[1] <- -0.51; adata$vSMCR[1] <- 0.19), make both OSF copies byte-identical, and pin the metafor version.

P3 — low

ADV-002 — Divergent duplicate analysis copies + no pinned metafor version (hygiene). The same analysis exists as two non-identical scripts across two OSF projects with different hard-coded indices, and neither records a lockfile/sessionInfo() (exactly what enabled ADV-001). The Averbeck effect is also not present in dat.csv (computed externally from a t-statistic and hand-entered) — this is disclosed in the script comments and the manuscript Figure caption, so it is transparent, but it is the one reproducible seam worth making explicit. Fix: single canonical script + data in one OSF project; add renv.lock/sessionInfo(); sync the J2QGS/Submission copy.

What this audit does not guarantee

  • The five documentary claims about the retracted Hofmann et al. (2015) (C16–C20: the "1.07" Hedges' g for Lee, the Anagnostou d-values 0.13/0.22/0.64, the included-vs-excluded 0.83/0.49 averages) cannot be checked against the retracted source and are marked ➖. The audit verifies the authors' own analysis, not every fact asserted about the retracted paper.
  • The Averbeck (2012) effect size (−0.51, v=0.19) was entered by hand from an external t-statistic; its correct entry is confirmed to reproduce the paper, but its derivation from the primary study was not independently re-run here (no Averbeck group means/SDs were shipped).
  • The editorial attestation "Analysis reproduced by André Kalmendal" is taken as administrative fact; it was not independently re-verified.
  • This run used metafor 5.0.1; the manuscript predates it. That the paper-cited code reproduces exactly on a modern metafor is a positive provenance signal. The J2QGS/Submission divergence (ADV-001) is a version-fragility defect whose magnitude may differ under the authors' original metafor.
