Verdict: the headline result fully reproduces. All six Test-for-Excess-Success power estimates and their product — the paper’s central claim that a replication of the six Dallas et al. studies has only probability 0.014 of uniform success — are confirmed both by running the authors’ own R code live and by an independent Monte-Carlo reimplementation (Studies 1 and 3 reproduce exactly under the documented seed; Studies 2 and S1 in closed form; the unseeded S2/S3 simulations fall within Monte-Carlo tolerance). The pooled meta-analytic Hedges’ g* = 0.2366 and the Table 2 power-planning figures also recompute. No primary statistic is wrong or undiscoverable. The three findings are all non-blocking: ADV-001 (P2) is an internal provenance inconsistency — Table 1 uses post-corrigendum input data while Table 2 was evidently produced from the pre-corrigendum meta-analysis (off-by-one cells as large as the introduction’s 1123 vs 1125 half-effect rows); ADV-002 (P2) is that the OSF project ships both pre- and post-corrigendum scripts at the root, so running the non-“AC” files gives Study-3 power ≈0.376 instead of the published 0.3626; ADV-003 (P3) is that two of the four simulation scripts ship without a seed (run-to-run drift, acknowledged by the authors). The excess-success conclusion (≈1.4% chance) is robust to all of these.

Findings (for the authors)

P2 — medium

ADV-001 — Table 1 and Table 2 are built from different data revisions (internal provenance inconsistency). The published Table 2 values (282/322/377/465/658 and 1123/1284/1502/1858/2626) reproduce exactly only from the pre-corrigendum meta-analysis (Study-1 right-label n=55, pooled g=0.2366623, verified live with MetaanalysisPower.R). The paper’s Table 1 power estimates and the 0.014 product, however, use the post-corrigendum inputs (Study-1 n=54 and the Study-3 no-label corrections), i.e. the “AC” files, whose meta-analysis run gives 282/322/377/466/658 and 1123/1285/1503/1859/2627. Because the in-text pooled g* = 0.2366 is consistent with both (0.2366623 vs 0.2365894 both round to 0.2366) and the 282/377/1123 astronaut anchors agree, the discrepancy is easy to miss: the Table-2 95% row (465 vs 466) and the entire g/2 half-effect block (1284/1502/1858/2626 vs 1285/1503/1859/2627) were generated from the older value of Study-1’s sample size. Why it matters: an internal-consistency defect (one paper, two data versions) rather than an error with any impact on conclusions — the headline 0.014 and all policy-relevant sample sizes are unaffected. Fix: regenerate Table 2 from the post-corrigendum MetaanalysisPowerAC.R (full 282/322/377/466/658; half 1123/1285/1503/1859/2627) or explicitly disclose that Table 2 used the pre-corrigendum n; ensure a single self-consistent data version across all exhibits.

ADV-002 — OSF code ships two revisions at the project root; the most prominent (non-“AC”) scripts do not reproduce the published Study-3 power. osf.io/xrdhj contains pre-corrigendum Analysis.R/Study1.R/Study3.R/MetaanalysisPower.R (README dated Oct 2019–Feb 2020) along with the post-corrigendum “AC” set (READMEAC dated 14 Jun 2020). Running the top-level Study3.R yields Study-3 power ≈0.376 (live re-run; shipped Results.txt prints 0.37647), not the paper’s Table-1 value 0.3626, because Study3.R still uses the pre-corrigendum no-label parameters (mean 1441.45, SD 382.43, n=83) instead of the corrected 1436.79/378.47/81. A downloader following the article’s generic “code at osf.io/xrdhj” pointer can easily run the wrong files; only the AC variants reproduce Table 1. Both give product ≈0.014, so the headline is robust, but the code-to-paper trace is ambiguous without reading READMEAC.txt — which is a clear reproducibility/documentation hazard. Fix: move the legacy pre-corrigendum files into a labelled legacy/ subfolder, leave the AC set canonical at the root, and add an explicit data-availability note directing readers to the post-corrigendum files.

P3 — low

ADV-003 — two of the four simulation scripts ship without a seed. StudyS2.R and StudyS3.R contain no set.seed(), so the paper’s 0.5667 / 0.4953 are single Monte-Carlo draws that cannot be reproduced bit-for-bit. Re-runs drift well within the Monte-Carlo SE (≈0.0016 for 100,000 replications): S2 → R 0.56738 / Python 0.56610; S3 → R 0.49435 / Python 0.49552. Studies 1 and 3 do ship a seed (3947194) and reproduce exactly. The authors’ own README warns “your numbers may vary,” and the inference is unaffected. Fix: publish fixed seeds for S2 and S3 (as already done for Studies 1 and 3) so the exact reported figures are byte-reproducible.

What this audit does not guarantee

  • Open data = No. No raw trial-level data is shipped (by design — the TES consumes only the summary means/SD/n of Dallas et al.). Consequently the background study’s numbers are inputs, traced here only for internal consistency with the scripts, not recomputed from primary data. The Dallas et al. reproduction record itself (banner “reproduced by N. Brown, P. Langford”) is not independently verifiable from the retrieved OSF nodes (C28 ➚).
  • This is a “methods/statistics-analysis” paper (Francis & Thunell), not a study re-analysis; the six power values are Monte-Carlo estimates whose exact decimal depends on the RNG stream. We report accepted-draw agreement (— two independent draws everywhere within SE, exact for the seeded studies), not a single bit-for-bit global reproduction for the unseeded studies.
  • The mediation analyses explicitly excluded by the authors (insufficient summary information) were not and cannot be checked.
  • Editorial review files and the Meta-Psychology platform-supplement were not in scope; only the paper text, the OSF code node, and the article banner were audited.
