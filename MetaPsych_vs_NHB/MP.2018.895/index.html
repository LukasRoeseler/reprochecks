This is a reproducibly strong empirical paper whose core result fully reproduces. All five experiments' primary statistics — every sensitivity slope mean/SD, every bias % mean/SD, every paired and one-sample t-test (t, p, dz, 95% CI), and every Bayes factor — reproduce from the shipped raw per-trial data to the manuscript's own reported precision, and the independent R and Python recomputes (both closed-form, deterministic) agree exactly with each other and with the paper. The headline finding — that a standardized y-axis range of ~1.5 SD improves sensitivity to depicted effect size and reduces bias relative to the full (0–100) and minimal ranges, replicating across bar and line graphs and across a 2 SD→1 SD range sweep — is robustly confirmed. No P0 or P1 issues were found. The 10 findings are all secondary/transparency in nature: the shipped notebook does not run as distributed (ADV-001); the abstract's "57 participants" does not match the 71 recruited / 58 analyzed (ADV-002); the cross-experiment summary tables A3/A4/A5 silently use a different participant sample for Exp1 ({1,3} vs the main text's {1,8}) and the N=9 (not N=11) sample for Exp3 (ADV-003/004); the Exp3 unplanned sub-analyses report dz and Bayes factors computed with an n=11 denominator under a df=8 (N=9) test (ADV-005); plus four P3 hygiene/typo items (df, trial-count, incomplete-data disclosure, one non-reproducible SD and a loose pooled percentage). None alters any conclusion.

Findings (for the authors)

P2 — medium

ADV-001 — The shipped analysis notebook is not runnable as distributed. Witt_AnalyzeGraphSD_V4.Rmd hardcodes setwd("C:/Users/jkwitt/Dropbox/InfoVis/bigLittle") (the author's local Dropbox) and is an interactive document with many exploratory chunks, so it cannot be executed end-to-end to regenerate the tables. The paper's "Open and reproducible analysis: Yes / Analysis reproduced by: Tobias Mühlmeister" badge therefore requires manual path-fixing and chunk reassembly. The analysis itself is fully reproducible from the raw data — this audit did it in both R and Python — so this is a packaging/actionability defect, not a substantive one.
Fix: ship a self-contained, relative-path script plus a README documenting the exact per-experiment exclusion lists and the effect-size→condition mapping.

ADV-002 — Abstract/main text "57 participants" does not match the data. Data files hold 71 recruited (9/14/13/20/15); after the paper's IQR-outlier exclusions the analyzed total is 58 (7/11/11/16/13). Neither equals 57.
Fix: restate as recruited=71 / analyzed=58 with per-experiment counts, or explain the 57 figure.

ADV-003 — Cross-experiment tables A3/A4/A5 for Experiment 1 use a different participant sample than the main text. The main-text Exp1 analysis excludes {1,8} (giving Std .47 / Full .30 / Min .28, t(SDvsFull)=3.84). The summary tables (.28/.46/.27) reproduce only under exclusions {1,3} (t would be 4.31). This is an undisclosed sample switch between an experiment's own analysis and its row in the cross-experiment summary.
Fix: disclose per-sample exclusions or recompute the summary row on the same sample as the main text.

ADV-004 — Cross-experiment tables A3/A4/A5 for Experiment 3 silently use the N=9 sub-analysis sample. Table A3 (.21/.58/.49), A4 (.09/.46/.25) and A5 (−25/14/23) match exclusions {2,3,4,5} (N=9), whereas the main text reports Exp3 at N=11 (excl {3,4}): .24/.62/.55. The two extra sub-analysis exclusions leak into the summary tables without statement.
Fix: label the per-experiment N in the summary tables, or make Exp3 consistent (N=11) with the main text.

ADV-005 — Exp3 unplanned sub-analysis dz and Bayes factors use an n=11 denominator under a df=8 (N=9) test. Every sub-analysis t-value reproduces, but the reported dz and BF equal t/√11 (the full N), not t/√9: e.g. d=.3–.8 Std-vs-Full t=9.310 gives dz 2.81 (=9.31/√11) vs 3.10 (n=9) and BF 6016 (n=11) vs 1460 (n=9); d=0–.3 Std-vs-Full dz .85 (=2.82/√11) vs .94, BF 3.76 (n=11) vs 3.36 (n=9). Internally inconsistent effect sizes/BFs for the stated degrees of freedom.
Fix: recompute dz and BF with the analytic n=9 denominator, or correct df if n=11 was intended.

P3 — low

ADV-006 — Exp4 standardized-bias test df typo. Reported t(14)=0.73, should be t(15) (N=16); the value 0.72 reproduces and the conclusion (bias ≈ 0, ns) is unchanged.
Fix: correct to t(15)=0.72.

ADV-007 — Exp1 incomplete participant described as 431 trials; data show 430. No effect on results.
Fix: correct to 430 or clarify rounding.

ADV-008 — Several <480-trial participants retained without disclosure. Exp4 retains S6=405, S14=389; Exp5 retains S5=289, S9=379; only the single Exp1 case is disclosed. Regressions use whatever trials are present, so results hold, but completeness is unequal and unreported.
Fix: report per-participant trial counts and justify retention.

ADV-009 — Exp1 Table A5 full-bias SD not reproducible. Table lists −27 (SD 5); the mean reproduces (SD ≈10.2 for any natural sample) and the minimal-bias SD is 19.5 vs 21. Cosmetic.
Fix: verify and correct the Exp1 Table A5 SD entries.

ADV-010 — Pooled response-category percentages are only approximate. Fig 2's "86%" (~86.7% all-trials) reproduces; Fig 3/prose "49% minimal-big" does not (54.4% d>0.1 / 42.0% all trials). Loose wording about subset and pooling. No inferential impact.
Fix: specify the exact trials/conditions/exclusions behind pooled percentages.

What this audit does not guarantee

  • No live author-notebook execution. The shipped Rmd was not run end-to-end because it hardcodes the author's local path and is interactive; every statistic was instead independently recomputed from the raw per-trial data in R and Python, which agree with the paper. A genuinely byte-level run of the author's script is not possible as shipped.
  • Stimulus construction (C3) not re-derived from scratch. The simulated-data step has no fixed seed in the repository; we verified the resulting per-trial files (effect-size codes, axis conditions, trial structure) but did not regenerate the stimuli. Marked ➖.
  • Bayes factors were computed analytically (BayesFactor ttest.tstat with the medium prior, rscale=0.707), matching the author's stated convention; we did not reproduce them via full posterior sampling.
  • Demographic/procedural prose (e.g., monitory resolution 1028×1024) and the qualitative Discussion assertions were not part of the numeric-statistical verification.
  • The pooled Fig 2/3 response percentages (ADV-010) depend on an ambiguous pooling definition, so our ≈ values bracket, rather than exactly pin, the paper's summary figures.
