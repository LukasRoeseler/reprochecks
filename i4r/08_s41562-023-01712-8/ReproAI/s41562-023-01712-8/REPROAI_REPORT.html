This is an exemplar of reproducible meta-research. Every quantitative synthesis the umbrella review actually performs — the random-effects pooled correlations, 95% CIs, k, N and p-values for the statistically-credible effects — is recomputable from the shared study-level data, and my independent R + metafor re-pooling reproduces 18 of 18 paper-quoted effects to the authors' 2-decimal precision (e.g. literacy r = −0.14 [−0.20,−0.09], k = 38, N = 18,318; internet→depression r = 0.25 [0.22,0.27], k = 118, N = 527,696). The numbers are not hand-typed: the manuscript is a papaja R Markdown document whose every headline figure is computed dynamically from the data by an explicit targets pipeline. PRISMA flow arithmetic and the credibility tallies (43 = 22 + 21 effects; 32 = 17 + 15 reviews; 88−66 = 22; 163−142 = 21) are all internally consistent, and a second-language Python recompute confirms direction and magnitude. The one medium finding (ADV-001) is a traceability gap, not an arithmetic error: the shipped raw quality file contains 217 reviews while Table 1 / the reliability percentages and the aggregate 2,451-studies / 1,937,501-participants totals are computed over an internal 102-review subset, so those descriptive tallies cannot be regenerated from the raw CSV alone without running the pipeline. No fabricated, self-contradictory, or load-bearing-wrong number was found.

Findings (for the authors)

P2 — medium

ADV-001 — Risk-of-bias and aggregate-sample tallies are not regenerable from the raw shared data alone (denominator 102 vs 217). The shipped QualityAssessment.csv contains 217 review rows (206 with a "Consensus" rating) and Reviews.csv contains 217 rows, yet every Table-1 reliability percentage (93/102 low heterogeneity; 86/102 low characteristics; 71/102 low search; 71/102 unclear eligibility; 20/102 high screening; 37/102 unclear screening; 52/102 high dual-quality) and the abstract's "medium-to-high risk of bias in 95/102" use a denominator of 102 "reviews providing unique effects." That 102-row denominator is created inside the pipeline (make_table_df "main" subset; PRISMA stage 11), not derivable from the raw CSV by inspection. Computing the tallies naively over the shared 217/206 rows gives different named counts (e.g. low-on-all-criteria = 11, not the reported 7; heterogeneity-low = 186/206 = 90%, not 93/102 = 91%). Likewise the headline aggregates "2,451 primary studies / 1,937,501 participants" are pipeline de-duplicated sums over the selected effects, whereas a naive sum of Reviews.csv gives ≈4,948 studies / ≈6.34 M participants (many primary studies appear in >1 review). The pipeline is self-consistent and the numbers are generated, not fabricated — but a reader working from only the shared data cannot regenerate them. Fix: ship a derived 102-review quality table (or an explicit review→subset mapping) next to the 217-row raw slab, and add a data note that the 2,451 / 1,937,501 totals are de-duplicated aggregations over selected effects.

P3 — low

ADV-002 — Credible-effect significance prose elides the non-significant effects. Education: "13 of 22 ... with the remaining six significant at 95%" (13+6=19 ⇒ 3 of 22 unnamed and n.s.); Health: "14 of 21 ... with the remaining four significant at 95%" (14+4=18 ⇒ 3 of 21 n.s.). Arithmetically consistent but the "remaining X" phrasing implies a full partition. Fix: add "and 3 were not statistically significant."

ADV-003 — Code hygiene: stray token and identity conversion. make_forest_plot.R line 1 begins "t #' .." (stray token); conversions.R::b2r is an identity (r = beta) with a TODO. No effect on the verified d/r/z effects (all 18 reproduced), but latent for beta-origin effects. Fix: remove token; document/standardise the beta→r transform.

ADV-004 — Environment/version documentation. Methods cite R 4.3.0; this host ran R 4.6.1 / metafor 5.0-1 (non-load-bearing: closed-form estimator, exact match). A pinned renv.lock is present but a full clean-session targets run (incl. webshot/webshot2 figure render + Python PDF merge) was not executed here. Fix: publish sessionInfo() / the renv.lock commit.

ADV-005 — Missing-value sentinel must be replicated. The shared Studies.csv uses −999/""/"#N/A" as NA markers which the authors' loader (read_sheet) maps to NA before mean-N imputation; a reimplementer who misses this (as this audit initially did) sees 27 rma failures ("sample sizes <= 0") and must re-run with the sentinel handling — a reproducibility cliff for reusers, not an error in any paper number. Fix: document the sentinel in the data README.

What this package already does right

  • Full code + data sharing: analysis scripts, a complete targets pipeline, and the underlying study-level data are public on GitHub and mirrored on OSF.
  • Computational provenance: the manuscript is a papaja R Markdown file whose headline statistics are inserted by inline code reading pipeline outputs (make_manuscript_info.R, report_effect(ce, "47569_001"), etc.) — the exact values are generated, never hand-typed.
  • True quantitative synthesis: study-level correlations/SMD/beta/Fisher-z were converted to a common metric and re-pooled with metafor (random effects), a genuine republication-of-data rather than a summary-of-summaries.
  • Primary synthesis is exactly reproducible: 18/18 quoted pooled effects, CIs, k, N and p-values match to the paper's precision.
  • Internally consistent: PRISMA arithmetic, credibility tallies and the abstract range all reconcile.

What this audit does not guarantee

  • No end-to-end targets run. The full graph (renv package set incl. webshot/webshot2 for table/figure render and the Python PDF-merge step) was not installed and executed, to avoid modifying the environment; I reproduced the numeric backbone (meta-analysis, conversion, N-imputation) instead. The figure RNG/jitter and rendered-PDF byte-reproduction were therefore not checked.
  • ADV-001 internals not hand-rebuilt — the 217→102 denominator mapping and the de-duplicated aggregate totals are pipeline-internal and were not re-derived by hand (hence the P2 traceability note rather than a claim I could independently close).
  • External background citations (PROSPERO record text, Parry et al. 47-study r=0.38, Hale & Guan 66/67 self-report, 622/69/19 psychometrics) are cited from other literature and were not re-verified (➖ in the inventory).
  • Substantive validity (e.g. appropriateness of meta-analysing high-I² heterogeneous pools, clinical/public-health interpretation) is out of scope; this audit addresses reproducibility and internal consistency only.
