A clean, fully reproducible empirical package. The authors shipped a complete Harvard Dataverse package (R script + Replication_data.RData + README). Running the author's exact multilevel specification (lmer(..., (1|party)+(1|country), REML=FALSE)) on the shipped data reproduces all three regression tables coefficient-for-coefficient, to the manuscript's own 3-decimal precision. The paper's own (lme4) numbers reproduce exactly, so the analysis is internally reproducible; the non-uniqueness is an identification/robustness property the authors should disclose. Findings (for the authors)

P2 — medium

ADV-001 — The headline RRP model is not uniquely identified under ML at N = 58; an independent recompute lands on a different optimum. R lme4 with REML=FALSE reproduces Table 1 Model 5 exactly (interaction −0.868, SE 0.317, p=0.008). But the same crossed two-random-intercept (party, country) ML specification, fit in Python 3.8 statsmodels 0.14.1 MixedLM on the same 58 complete cases, converges to a different mode (interaction −0.555, SE 0.307; also −1022.9 vs −294.9 for the intercept, 0.517 vs 0.151 for year) and reports a non-positive-definite Hessian. Cause: with 58 observations spread over 22 parties and 19 countries, the multilevel ML likelihood is shallow/near-degenerate (the lme4 fit itself produces boundary/singular party-variance warnings), so the point estimates are optimizer- and starting-value-sensitive. This is not evidence of fabrication — the shipped lme4 pipeline reproduces the manuscript exactly — but it is a genuine identification caveat for a small-N cross-national mixed model. Fix: disclose the fragility; add a REML or optimizer/starting-value sensitivity check; note the Satterthwaite denominator-df limitation at this N.

P3 — low

ADV-002 — Abstract sample scope ("187 parties, 30 countries") not exactly recoverable. The shipped data has 730 unique party IDs across 38 countries; the complete-case all-parties model (Table 2 M5) uses 175 parties in 29 countries. The abstract's rounded scope describes neither the raw file nor the model sample exactly. No regression result is affected (the tables' own N/Nparties reproduce). Fix: state that the scope refers to the pre-listwise-deletion window.

ADV-003 — Table 1 Model 2 interaction significance star is convention-dependent. Interaction M2 = −0.663 (SE 0.338). Under the lmerTest Satterthwaite approximation p = 0.0548 (not <0.05), but under a Wald/z approximation p = 2·(1−Φ(1.964)) = 0.0495 (<0.05), which is the basis of the manuscript's '*'. This is a Wald-vs-Satterthwaite convention artifact, not a data error; M3–M5 (the models carrying the paper's claims, including headline M5 p=0.008) are clearly significant either way. Fix: report the M2 p-value explicitly.

ADV-004 — Illustrative predicted values (20% / 14%) not exactly reproduced. At M/F=2 with mean covariates, Model 5 reproduces 21.5% (VC −5) and 15.7% (VC +5) vs. the paper's round 20% / 14%. Direction is correct. Fix: quote the reproduced values or the covariate reference points.

ADV-005 — Case prose: "PVV vote share increased by about 3 p.p." vs. dataset vote change −5.37 in 2017. The same passage also describes the party "losing votes (10.1% vs 15.5%)"; the "+3 p.p." figure is ambiguous and does not match chgvotelagged = −5.37 for PVV 2017. Qualitative-section clarity only. Fix: clarify the reference for the +3 p.p..

ADV-006 — Data hygiene / version drift. Party-name strings are double-encoded (UTF-8 mojibake, e.g. "SwsP…"); the README states R 4.1.2 while the audit host uses R 4.6.1 (lme4 2.0.6/lmerTest 3.2.1). No numeric reproduction was affected. Fix: re-code labels and pin package versions (renv.lock) with the RData.

What this package already does right

  • Complete, working replication package on Harvard Dataverse (code + data + README), reachable from the paper's Data Availability Statement.
  • The author's model specification runs out-of-the-box on the shipped data and reproduces every table entry (Tables 1, 2, 3) to 3 decimal places — including all significance stars where the underlying p is unambiguous.
  • The headline interaction (male-dominated electorate × electoral decline → more women MPs, and the reverse for success) is statistically significant in the RRP-only models and null in the pooled all-parties models, exactly as claimed.
  • Internal consistency is high: N, cluster counts, LogLik, AIC, BIC, quota p≈0.06, and the SVP/PVV case-study data points all agree with the manuscript and the dataset.

What this audit does not guarantee

  • The author's full script also renders figures (Figure 1–7, A1–A5) via ggplot2/interplot and writes TableN.doc files via stargazer. Those exact packages/renders were not re-run (several are not installed on this host); figure-only code has no bearing on the primary inference, which is fully verified. No shipped .doc/figure files existed to byte-compare.
  • Small-N identification: because the ML mixed-model likelihood is not uniquely identified at N=58 (ADV-001), the numeric headline coefficient is optimizer-sensitive even though the paper's lme4 value reproduces exactly. The substantive direction and significance are robust, but readers should not over-interpret the exact point value.
  • Case-study qualitative evidence (news sources, candidate-list placements, campaign tactics) was checked only to the extent it appears as dataset variables (women-MP shares, M/F ratios); the primary/secondary source narratives themselves were not independently re-verified.
  • Version gap: audit used R 4.6.1 (lme4 2.0.6 / lmerTest 3.2.1) vs. the author's R 4.1.2. Every reproduced value still matched, so no drift was observed; this does not rule out drift in un-tested figure code.
