This is an empirical comparative-historical political-economy paper whose headline evidence is a set of dynamic, country/date fixed-effects panel regressions (Tables 3 & 4) on an original, author-compiled cross-national employment-structure dataset (disruptive capacity, 1754–2013), plus descriptive statistics (Table 2), a mobilization validation (Fig. 1) and counterfactual simulations (Figs. 3–4).

Scope limitation stated up front: the published article provides no replication package and no data/code archive link (see ADV-001, P1) — a full-text search for osf / dataverse / github / zenodo / "data and code" / "available at" / doi returned zero replication links, and only a "supplementary online appendix" is cited (fn 12, p. 678) with no deposited artifact. Consequently no external/numerical reproduction of any headline coefficient, SE, CI, N, descriptive, figure-validated, or counterfactual value was possible. The independent reimplementation in R therefore consists of every internal-consistency check that is computable from the printed tables and prose alone (closed-form arithmetic: within-SD monotonicity, point-vs-CI midpoint, prose-vs-table sample/sign reconciliation, counterfactual arithmetic). Findings (for the authors)

P1 — high

ADV-001 — No replication dataset or code is provided; the article's central empirical results are not independently reproducible as published. The paper's principal contribution is a quantitative test of the "social forces" account on an original cross-national, long-run employment-structure dataset (disruptive capacity, 1754–2013; ~179 countries), and its headline evidence (Tables 3 & 4 long-run multipliers, SEs/CIs, N; Table 2 descriptives; Figure 1 validation; the counterfactual simulations) all depend on this unshipped data. A full-text search of paper_extracted.txt (1,872 lines) for osf, dataverse, github, zenodo, replication, "data and code", "available at", doi found no data/code link; only a "supplementary online appendix" is cited (fn 12, p. 678), with no deposited archive. The many sourced covariates (Polity2, V-Dem v2x_polyarchy, PWT+Maddison GDP, Morrison–Murtin education, Banks urbanization, Bourguignon–Morrison/Babones–Rivadulla/Solt inequality, Vanhanen landlord index) are cited but not assembled into a package. Result: the paper's numbers cannot be regenerated or audited independently — a primary-analysis-reproducibility gap (P1 per §9). Fix: deposit the full replication bundle (data + estimation code + counterfactual scripts) on OSF/Dataverse/Zenodo and add a data-availability statement and link to the article. A clean-session R run of that code should reproduce the headline col. 6 multipliers (Polity2 DC = 4.168**; ED DC = 2.812**) and Table 2 to the printed precision.

P2 — medium

ADV-002 — Table 1 internal inconsistency: prose "42 points higher (0–100)" vs tabled "142", and the ΔAverage column is not interpretable on a 0–100 scale. The prose (p. 680) states that where union-membership data are available "the average democracy score is 42 points higher (on a 0–100 scale) than the average score in all countries and years for which data exist." Table 1's column (labeled in the note as "ΔAverage Polity2," i.e., sample-min_{us} overall average difference) lists 142 for all three union rows (union membership, per-capita, density) — a 100-point gap from the prose figure — and every value in that column (111–142) exceeds 100, which is impossible for a difference on a 0–100 scale (and as a plain average also impossible, since the rescaled Polity2 mean is 67.32). Either the column is mislabeled or the prose figure is wrong; both cannot hold. Unresolvable without the data. Fix: recompute the availability-bias from the Polity2 sample, correct the label and/or the prose value, and reconcile 42 vs 142. Because no included coefficient is at stake this is not a P1, but it is a genuine self-contradictory reported value (P2, §9).

P3 — low

ADV-003 — "only 60% of the coverage of disruptive capacity" is a rounding overstatement. Table 1 N(Polity2): strikes per capita = 4,378; disruptive capacity = 7,610 → 4,378/7,610 = 57.5%, not 60%. Substantive point (strikes data cover far less) still holds. Fix: restate as "about 58%" / "roughly three-fifths."

ADV-004 — Exhibit hygiene: mirror-stored tables and bitmap figures limit machine-verifiability. The AJS "track" PDF stores Tables 1/3/4 as mirrored right-to-left text and Figures 1–4 as embedded bitmaps with no extractable data cache, so exact negative-coefficient magnitudes and the 0.91/0.24/0.08 SD figure values could not be read programmatically without manual reversal. No effect on the paper's conclusions; resolved by the ADV-001 deposition of tidy CSV tables + code. (Also: the Table 4 col. 1 pair [2.13, 3.15] vs point 1.406 failing its own point-in-CI test in my transcription is a mirror-reversal pairing artifact, not a paper error — see §Caveat and REPRO_STANDARDS §3/§12.)

What this audit does not guarantee

  • No numerical verification of any headline result. With no replication dataset or code shipped (ADV-001), none of the long-run multipliers, SEs/CIs, N, descriptives, Figure 1 validation values, or counterfactual magnitudes could be recomputed. The R "reimplementation" verified only closed-form internal consistency; it is not a byte-level reproduction of the author's regressions.
  • Exact CI endpoints and negative-coefficient magnitudes for the mirrored tables carry transcription uncertainty; verdicts for those rows are directional (sign/significance) only and marked ➖ for magnitude.
  • Statements about sample-bias magnitudes, stationarity tests, robustness spec checks, and any non-tabulated results described only in prose/references were not auditable.
  • Second-language recompute (§5) and live execution (§6) were impossible by design: no author code or data exists in the audited package.
  • The engine's internal-consistency computation itself is deterministic and auditable from the enclosed console log; the interpretation of the mirror-reversed table values is the auditor's and flagged as such.
