Findings (for the authors)

P2 — medium

ADV-001 — The a-insensitivity Spearman retest correlation differs between text and Figure 2 captions. Section 4.2 states "ρ=0.73 for the control treatment and ρ=0.74 for TP," but the Figure 2 panel captions read "ρ=0.77 (control)" and "ρ=0.70 (TP)" (paper_extracted.txt lines 402–403 vs. line 428). Both groups disagree, and the two figures' control values cannot both be the correct a-index retest correlation. Notably, Figure 2's control value (0.77) equals Figure 1's b-index control value (0.77), consistent with a panel-caption copy-paste error. Impact: secondary/descriptive (a retest-correlation shown in a figure); does not affect the headline inference (TP raises a-insensitivity; no effect on b). Also not independently recomputable without raw data (➖). Fix: recompute both a-index ρ from the raw per-subject a-values and reconcile the text with the figure captions (correct the wrong one, most likely the figure).

P3 — low

ADV-002 — No public replication package / raw data for a lab-experiment paper. No per-subject matching-probability data or analysis code is publicly available (Zenodo es-replication-repository returns 0 hits for ECTA14370; the Econometric Society page exposes only the Supplement PDF). This paper predates Econometrica's mandatory data-editor replication policy (~2019–2020), so this is a provenance/reproducibility limitation rather than an author error — but it blocks independent verification of 8/19 empirical claims. Fix: retroactively archive the anonymised data + cleaning/regression code (e.g. in the ES Journals' Zenodo community) with a README mapping every exhibit to its producing script.

What this paper already does right

  • Methodologically clean: the index definitions are internally calibrated and their means, SDs, SEs, and the Model-1 OLS point estimates are mutually consistent across Tables III–V and the Supplement's SC.I — no impossible or self-contradictory headline number was found.
  • The linearity of the indexes makes Table III fully reconstructable from the Supplement's summary statistics, a strong positive cross-check.
  • Sample-size and denominator arithmetic is consistent end to end (104→99, 198, 1584, 496, 191), and the weak-monotonicity exclusion counts reconcile exactly with the reported percentages and the Supplement's N=191.

What this audit does not guarantee

  • No raw-data re-execution. No author data or code is publicly available, so regression standard errors, Wald Chi², R², Spearman ρ, the Wilcoxon/Mann–Whitney statistics, and Table III medians could NOT be independently computed. All such entries are marked ➖ with the reason; they should not be read as verified.
  • Figures 1–2 are raster images in the PDF; their panel-level percentages ("two-thirds of the dots to the right of the diagonal") were not extracted/verified, and the ρ values are read from the caption text only.
  • Pilot-response-time figures (36 s without TP; 30 s limit) are authors' pilot data, not independently checkable.
  • The proposition-track items C6 (orthogonality) and C7 (α = b/(2a)+½) derive from the companion working paper Baillon et al. (2018b), not from this manuscript; marked ➖ here.
