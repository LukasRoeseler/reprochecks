Verdict: the paper’s headline statistics are not independently reproducible from the shipped materials. The paper repeatedly states “Data are provided in the Supplementary Materials,” but the OSF project referenced by the DOI ships only a summary-level supplement (descriptive tables S1–S4); there is no raw participant-level dataset, no JASP/WEKA analysis files, and no analysis code anywhere (OSF node e285f: public, 0 children, 1 file). What can be checked is clean and largely internally consistent: all N/exclusion arithmetic reproduces; the section 3.1 one-sample t-tests and Cohen’s d for males (t=4.79, d=0.22) and females (t=18.21, d=0.46) recompute correctly from the reported means/SDs/normative values; all eight Table 3 F-measures check out against their own precision/recall; and 9 of 10 supplement Table S2 item t-tests/d’s are internally consistent. Findings (for the authors)

P1 — high

ADV-001 — The data (and analysis outputs) promised as “in the Supplementary Materials” are not actually provided; the primary statistics are therefore not independently reproducible. Sections 2.1/2.2 and the Discussion state that data (including “open access data”) are provided in the Supplementary Materials (paper_extracted.txt ≈ lines 234, 523–525). The OSF project behind the DOI (node e285f, public, zero children) ships a single file, the supplement PDF jcm-09-03350-s001, which contains only summary descriptive statistics and ML parameter listings (Tables S1–S4). No raw participant-level responses, no derived-variable dataset, no JASP 0.14 analyses, and no WEKA 3.9 arff/models/code are present anywhere. Why it matters: the primary inferential claims — Regression 1 (R²=0.103), Regression 2 (R²=0.356) with all 12 coefficients, and the headline ML sensitivity (≈0.759) — rest entirely on data a reader cannot obtain; a thorough recipient cannot confirm any of them. Fix: publish a de-identified participant-level dataset (raw item responses + the 18 derived variables), the JASP .jasp analysis files for Tables 1–2, and the WEKA 3.9 configuration/ARFF pipeline on OSF node e285f, with a README tracing raw → derived → analysis. Then re-run Tables 1–3 and Table S2 end-to-end.

P2 — medium

ADV-002 — Supplement Table S2 Item 1’s group means are inconsistent with its own reported t and Cohen’s d. Printed means 2.62 (SD 0.91, high) vs 1.84 (SD 0.91, low), n=393/1642, recompute to a pooled t=15.263 and |d|=0.857, but the table reports t=27.95 and |d|=1.57. The reported t and d are mutually consistent with each other (and with a mean difference ≈1.43, roughly double the printed 0.78), and Items 2–10 in the same table are internally consistent — so a global extraction artifact is implausible. Fix: re-derive Item 1 from the raw data and correct the means (or the t/d) so all three agree within rounding.

ADV-003 — Unstated sign convention for Cohen’s d in Table S2. All ten items print a negative d (low-minus-high), internally consistent across the table but never stated; a reader expects high-minus-low (as used in §3.1). No conclusion changes (all items significant), so this is documentation hygiene. Fix: state the convention in the Table S2 legend (or flip the sign to high-minus-low).

P3 — low

ADV-004 — The abstract overstates the best sensitivity (“greater than 76%”). The best high-stress sensitivity in Table 3 is 0.759 (Logistic) = 75.9%, which is not greater than 76%; the Discussion correctly says sensitivity “approaching 0.759”. Fix: restate as “approaching 76%” or quote 0.759 exactly.

ADV-005 — Education-mean drift between paper text and supplement. §2.2 reports 15.35 (SD 3.43); supplement Table S1 reports 15.36 (SD 3.43). Fix: harmonize the two sources.

What this audit does not guarantee

  • No end-to-end reimplementation of the primary analyses. Because the authors shipped no raw data and no code, Tables 1–2 (regression) and Table 3 (ML metrics, feature selection) are marked ➖ not independently checkable rather than verified or refuted. A completed audit requires the authors to release the data/code (see ADV-001).
  • The supplement Table S2 and Table S1 numbers above were read from an automatic PDF-text extraction (pdfminer), which can misaligned two-column cells; item-level cell values were therefore treated with care, and only the Item 1 discrepancy that survives the 9-of-10 agreement pattern was elevated to a finding.
  • Normative Italian PSS-10 values (males 15.2/6.1; females 16.3/5.5, ref. [53]) are cited, not independently recomputed — the PSS-10 normative source was not fetched.
  • ML behaviour depends on random seeds/parameterization documented in Table S4 (WEKA defaults, seeds 1); without the raw training/test split we could not quantify classifier variance. Abstract wording aside, ROC 0.697–0.782 is consistent only at the stated two-decimal range.
