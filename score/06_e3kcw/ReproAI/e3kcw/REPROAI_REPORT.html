Findings (for the authors)

P1 — high

ADV-001 — Table 1's three main-effect columns are cyclically mislabeled. The printed column headed "Flow" contains the Quarantine-Length coefficients (e.g. worry .10, loneliness .12, unhealthy .08), the column headed "Mindfulness" contains the Flow coefficients (positive emotion .17, loneliness −.15, healthy .19, unhealthy −.12), and the column headed "Quarantine Length" contains the Mindfulness coefficients. Evidence: (a) the author-shared full-regression-results PDF (full_regression_results.pdf, OSF vuwg3) places identical values under correctly-labelled Quarantine/Flow/Mindfulness rows; (b) independent R and Python recomputation from the shipped .xlsx reproduces the PDF rows exactly in sign/magnitude/significance and, under the same row-label scheme, shows the printed Table-1 column order is rotated by one. Why it matters: a reader taking Table 1 literally would attribute quarantine-length's well-being effects to flow (and flow's to mindfulness); the prose directions are correct, and the headline moderation result sits in the two correctly-labelled interaction columns, so the central conclusion is not overturned. Fix: re-label Table 1 columns to Quarantine Length / Flow / Mindfulness / Flow × Quarantine / Mindfulness × Quarantine, regenerating from the script that produced the full-results PDF; add a regression script + convention note (see ADV-006).

P2 — medium

ADV-002 — Sample "% female" contradicts the shipped data. Manuscript: "73% female". Shipped data: 3721 (72.7%) code-1 vs 1394 (27.3%) code-2; the full-results PDF footnote states "a1=male, 2=female" — i.e. the data are ~73% male. Either the statement is wrong or the coding used in the report is reversed. Does not change any analysis (sex is only a covariate), but the sex-composition claim and the sign interpretation of the Gender β coefficients should be re-checked. Fix: confirm true gender coding against the identified data and correct the statement / footnote.

ADV-003 — Mindfulness descriptives not reproducible from shipped data. Reported M=2.50, SD=.47 (12-item CAMS-R average); shipped mindful total gives average 2.083, SD .389. (CAMS-R alphas also uncheckable — items not shipped, contribution to the ➖ bucket for that scale.) All other scales reproduce as averages, so this stands out. Does not affect any regression conclusion. Fix: recompute mindfulness from the raw 12 items (with item-5 reversal) and reconcile with the shipped total.

ADV-005 — "Region" described as a controlled covariate but absent from the model. Results prose lists region among covariates; the full-results PDF and Table-1 note list gender, age, education, sibling status, income, optimism, IU, SWL — no region term. Misdescribed method. Fix: either add region or remove it from the prose description.

P3 — low

ADV-004 — Age descriptives only approximate. M=21.36/SD=4.49/15–71 reported vs 21.60/4.39/15.55–70.90 in data (fractional, date-derived ages; 146 age NAs). Likely de-identification artifact plus undocumented missing handling. Fix: add an N/missing note and report age on the analytic sample.

ADV-006 — Analysis sample & standardization convention undocumented. The reconstructed betas reproduce sign/significance but not every 2-decimal cell (max |Δ| ≈ .015) and imply listwise deletion of 146 age-NA cases (analytic n=4969) although N=5115 is reported throughout. Fix: share the analysis script and state the centering/standardization and missing-data convention so all 40 cells reproduce to full precision.

What this audit does not guarantee

  • No author-code live run. No analysis script was shipped (only data + survey + full-results PDF), so no end-to-end execution of the authors' own code was possible. All statistics were regenerated independently in R 4.6.1 and cross-checked in Python 3.8; the closest documented convention (grand-mean-centered, fully-standardized OLS; listwise n=4969) yields sign and significance agreement with every cell but not byte-identical β in all cells (ADV-006).
  • Cronbach alphas for flow, mindfulness, depression, anxiety, positive/negative emotion, optimism, IU, SWL cannot be recomputed — only scale totals were shipped, not item-level responses. Marked ➖ with reason.
  • Survey duration (8.99 min) and the education/PhD split (97% / 3.5%) are not recoverable from the de-identified file. ➖.
  • The DOI node id e3kcw is not resolvable as an OSF node (the DOI is the PsyArXiv preprint handle); auditable materials were taken from the paper's own OSF link (vuwg3), whose released hashes matched exactly on download — the audited artifact is the current public release.
