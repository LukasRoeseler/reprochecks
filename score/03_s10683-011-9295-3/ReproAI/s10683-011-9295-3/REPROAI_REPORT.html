Findings (for the authors)

P1 — high

ADV-000 — No raw data or analysis code is deposited, so the paper's primary inferential statistics are not independently reproducible by a third party. Not a numeric error, but a reproducibility blocker under the ReproAI rubric (§9: a "primary statistic ... not reproducible" is P1). The paper (2011) cites no data/code link; the ESM (10683_2011_9295_MOESM1_ESM.pdf, retrieved and parsed) contains only Appendix A (instructions), B (hurdle model + M-estimators) and C (threshold derivations) — no per-pair dataset. "The complete test is available on request" refers to the questionnaire, not the data. Consequently all of Table 2 (WLS + bootstrapped quantile regressions), Table 3 (Wilcoxon values) and ESM B (hurdle/M-estimator coefficients) are classified ➖ (DATA-NA), and the exact two-sample KS p (fn14) is not computable. Fix: deposit the anonymized per-pair dataset and z-Tree/Stata analysis code (e.g. on OSF/Zenodo) and cite it; at minimum publish the aggregate cell data.

P2 — medium

ADV-001 — In-text Wilcoxon p-value does not correspond to its own reported W statistic. Main text (p.172): the Accountability group for md≥mr & pd≤pr prints "W = 1.120, p-value = 0.904". The reported "W" is a normal-approximation z throughout (verified: dozens of W↔p pairs in the paper map exactly to p = 2·[1−Φ(|W|)]). Using that identity, W=1.120 ⇒ p = 0.2627 (R and Python agree). The printed 0.904 matches W=0.120, the Accountability row of the adjacent md<mr, qd≥qr group (p=0.9049) on the same page — an apparent copy-paste. Both p-values are non-significant, so the conclusion ("accountability cannot be rejected here") is unchanged. Fix: correct the p-value to ≈0.263 (or report the exact signed-rank p) for the W=1.120 row.

ADV-002 — Internal inconsistency in the number of zero givers: Table 1/"90%" implies 7, footnote 19 & ESM Appendix B say 8. Table 1 "share offering nothing" (0.08 / 0.04 / 0.17) decomposes to integer counts of 2 / 1 / 4 = 7 of 72 (pooled 0.10 ≈ 7/72 = 0.097), which also reproduces the prose "positive transfers occur 90% of the time" (65/72 = 0.9028; with 8 zeros it would be 64/72 = 0.8889, i.e. ~89%). But footnote 19 (p.171) and ESM Appendix B both state "EIGHT dictators choosing s=0" (8/72 = 0.111), and ESM Appendix B's "unselfish (give ≥5%) DW=21, DB=22" implies 3 below-5% givers in DW and 2 in DB. The paper's own sources disagree by one observation. Fix: state the exact per-treatment counts of s=0 (and of s=0.01/0.02), then make Table 1 shares, the "90%" prose, footnote 19 and Appendix B mutually consistent.

P3 — low

ADV-003 — Pooled (s−xa) and (s−xl) means (−0.13, −0.11) differ from the unweighted average of the printed treatment means (−0.123, −0.117). The treatment-level (s−xa)/(s−xl) means are fully internally consistent with the qd/qr/s cell means under the stated prices (verified). The pooled figures are almost certainly computed from full-precision cell data (hence −0.13 / −0.11) while re-deriving from the 2-dp printed cell means gives −0.12 / −0.12 — a rounding-drift artefact, not an error. Fix: confirm pooled means are from raw cell data and add a rounding note.

ADV-004 — Pooled justice F-tests report df2=60 for n=72, implying an undocumented ~12-parameter unrestricted model; the pooled qnt-libertarian p just exceeds the stated "<0.0020" bound. 72−60 = 12 estimated parameters in the pooled robust/quantile regressions is not a plain two-parameter fit (which would be F(2,70)); the pooled specification (treatment dummies/interactions) is not documented in the text. Also, the text's "none ... can explain the pooled data (p-values<0.0020 in all the cases)" is marginally violated by the bootstrapped-quantile libertarian F=6.79(2,60) → p=0.0022 (all other pooled natural F's give p<.0001). Fix: document the pooled model (variables, df) and state p precisely rather than a blanket <0.0020.

ADV-005 — fn14 KS D=0.33 (n=24,24), p=0.089 is not matched by standard two-sample asymptotics. Two-sided asymptotic p for D=0.33, n1=n2=24 computes to ≈0.1465 (basic) or ≈0.0695 (Stephens finite-n correction). The exact two-sample p depends on the empirical-offer arrangement (raw data) and could plausibly be 0.089, but it is not independently computable here. Fix: recompute the exact (non-asymptotic) two-sample KS p from the raw offers and document the software/package used.

What this audit does not guarantee

  • No live or first-principles recomputation of the primary inferential results. Because no raw data or analysis code exists, Table 2 regressions (WLS robust, bootstrapped quantile), Table 3 Wilcoxon values, and ESM B hurdle/M-estimator coefficients were not recomputed — they are marked ➖ with reason DATA-NA. If the authors release the dataset, the natural next step is to rerun all of these from the raw pairs.
  • Exact KS p (fn14) and all **group-level SDs / cell minimum-maximum distributions** are based on the published cell statistics only and are not verifiable without raw data.
  • Not a byte-for-byte author reproduction. The closed-form checks (t, F, χ², W→p, thresholds, mean arithmetic) are deterministic and language-independent (R == Python), but this audit does not claim to replicate the original z-Tree/Stata implementation because none was shipped.
  • Interpretation, not statistics: whether the "bias principle" story correctly reflects subjects' motives is a substantive economic judgment, outside a reproducibility audit.
